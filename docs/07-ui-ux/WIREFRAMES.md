# 界面线框图

> 用途说明：使用低保真线框说明创建、解锁、分类、网站、账号、搜索、回收站和设置页面的基本布局。
>
> 状态：历史低保真线框 / 创建、解锁和锁定页面已由 ADR-014 废止
>
> 最后更新日期：2026-07-30

> 现行说明：本文保留早期页面探索供追溯。当前应用启动后自动进入主界面，不提供创建密码、解锁、锁定或自动锁定页面；现行布局以 M3 实现和 M4 执行计划为准。

## 1. 说明

- 本文只定义信息层级和主要操作，不代表最终颜色、字体和尺寸。
- 所有示例账号和密码均为虚构占位。
- `[...]` 表示按钮或操作。
- 敏感值使用遮挡符号表示。

## 6. 网站详情：宽窗口

```text
┌──────────────┬──────────────────────┬───────────────────────────────┐
│ 主导航       │ 示例代码平台         │ 私人账号                      │
│              │ example.test         │                               │
│ ● 分类       │ [打开] [复制网址]    │ 用户名                        │
│   搜索       │                      │ demo_user              [复制]│
│   回收站     │ 账号                 │                               │
│   设置       │ ───────────────────  │ 密码                          │
│              │ ● 私人账号           │ ••••••••••••      [显示][复制]│
│              │   工作账号           │                               │
│              │                      │ 测试令牌                      │
│              │ [+ 添加账号]         │ ••••••••••••      [显示][复制]│
│              │                      │                               │
│              │                      │ 备注                          │
│              │                      │ 仅用于测试                    │
│              │                      │                               │
│ [锁定]       │                      │ [编辑账号] [删除账号]         │
└──────────────┴──────────────────────┴───────────────────────────────┘
```

模块化体现为：

- 左侧主导航属于应用壳。
- 中栏属于网站与账号选择。
- 右栏属于账号详情。
- 编辑进入独立编辑状态，不在只读详情堆满输入框。

## 13. 数据损坏或恢复

```text
┌──────────────────────────────────────────────────────────────┐
│ 无法安全打开保险库                                          │
│                                                              │
│ 数据可能损坏、版本不兼容，或恢复过程未完成。                │
│ 为保护现有数据，应用已停止写入。                            │
│                                                              │
│ [查看诊断信息] [从备份恢复] [退出]                          │
└──────────────────────────────────────────────────────────────┘
```

不能提供“创建空保险库并覆盖”作为默认按钮。

## 14. 视觉优先级

1. 当前对象名称。
2. 主要任务按钮。
3. 非敏感摘要。
4. 敏感字段遮挡与安全操作。
5. 编辑、删除和更多菜单。

删除按钮不与保存按钮使用相同视觉强调。

## 15. 待验证问题

- [ ] 分类首页使用卡片还是紧凑列表。
- [ ] 账号列表宽度和右侧详情最小宽度。
- [ ] 密码显示按钮的位置和短暂显示时长。
- [ ] 字段拖拽排序与键盘排序方案。
- [ ] 搜索结果是否直接提供复制用户名快捷操作。
- [ ] 设置页面是否需要独立二级导航。
- [ ] 900 × 640 最小窗口是否足够。
