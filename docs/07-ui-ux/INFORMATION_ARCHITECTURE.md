# 信息架构

> 用途说明：定义用户如何在分类、网站、账号、字段、搜索、回收站和设置之间理解、定位和移动。
>
> 状态：初稿 / 待用户流程评审
>
> 最后更新日期：2026-07-30

## 1. 核心原则

- 主层级与数据模型一致。
- 分类负责组织网站，网站负责组织多个账号。
- 标签和收藏是横向入口，不改变主要归属。
- 搜索返回安全摘要，详情仍回到所属模块。
- 模块化不等于增加无意义点击。

## 2. 信息层级

```text
保险库
├─ 分类
│  └─ 网站
│     └─ 账号
│        └─ 字段
├─ 搜索
├─ 回收站
├─ 设置
└─ 锁定
```

首个公开版本候选：

```text
保险库
├─ 收藏
└─ 标签
```

## 3. 主导航

排序：

1. 分类
2. 搜索
3. 收藏（功能启用后）
4. 标签（功能启用后）
5. 回收站
6. 设置
7. 锁定

锁定是安全动作，固定在导航底部，不藏入多层菜单。

## 4. 分类

### 分类首页

显示：

- 分类名称。
- 网站数量。
- 新建分类。
- 排序或管理入口。

不显示：

- 密码。
- 全部账号字段。
- 回收站对象。

### 分类详情

显示：

- 分类名称。
- 网站列表。
- 每个网站的账号数量。
- 新建网站。
- 重命名、移动或删除分类入口。

网站名称允许重复时，同时显示网址或其他区分信息。

## 5. 网站

网站详情包含：

- 网站名称。
- 主网址。
- 打开和复制网址。
- 所属分类。
- 账号列表。
- 新建账号。

账号列表显示：

- 账号显示名称。
- 用户名或邮箱摘要，可按敏感规则隐藏。
- 不显示密码。

## 6. 账号

账号详情显示：

- 账号显示名称。
- 基础字段。
- 自定义字段。
- 显示或隐藏。
- 复制。
- 编辑和删除。

账号编辑页按以下顺序：

1. 账号显示名称。
2. 用户名。
3. 密码。
4. 邮箱（若启用）。
5. 自定义字段。
6. 备注。
7. 保存和取消。

字段实际顺序由用户调整，以上是新建默认。

## 7. 搜索

搜索结果分组：

- 网站。
- 账号。

每项显示：

- 名称。
- 所属分类。
- 所属网站，若为账号。
- 匹配原因，例如“账号名称匹配”，不显示敏感值。

搜索结果进入原始详情页面，不复制一套独立详情编辑器。

## 8. 回收站

按删除批次展示：

- 根对象名称和类型。
- 删除时间。
- 包含的网站或账号数量。
- 原位置。
- 恢复。
- 永久删除。

回收站不默认展示字段秘密。

## 9. 设置

设置分组：

### 安全与本机保护

- Windows DPAPI 自动加密说明。
- 剪贴板条件清除。
- 跨 Windows 用户或设备恢复限制。

### 数据

- 保险库位置，只读展示。
- 创建备份。
- 恢复备份。
- 导入导出，功能启用后。

### 外观

- 主题。
- 字体缩放，后续评估。

### 关于

- 应用版本。
- 数据格式版本。
- 开源许可证。
- 安全漏洞报告方式。

设置不展示主密码、密钥或账号数据。

## 10. 首次使用

```text
欢迎与本地说明
→ 创建主密码
→ 确认恢复限制
→ 创建保险库
→ 空状态
→ 创建第一个分类
→ 创建第一个网站
→ 添加第一个账号
```

不在首次使用中要求注册、联网或配置复杂安全参数。

## 11. 日常流程

### 从分类进入

```text
分类 → 网站 → 账号 → 复制密码或打开网址
```

### 从搜索进入

```text
全局搜索 → 结果 → 账号详情 → 复制
```

目标：从自动打开后的主界面到复制目标字段，常见路径不超过三次主要选择。

## 12. 新建流程

用户可以：

- 在分类详情新建网站。
- 新建网站后立即添加账号。
- 在网站详情添加更多账号。

不允许从任意页面弹出包含所有实体的超大表单。每一步属于对应模块。

## 13. 编辑流程

- 编辑网站不混入账号字段编辑。
- 编辑账号不修改网站共享网址。
- 编辑分类不显示所有后代字段。
- 复杂删除使用影响摘要。

## 14. 命名

界面统一使用：

- 保险库。
- 分类。
- 网站。
- 账号。
- 字段。
- 回收站。

不使用“项目”指代账号条目，避免与整个软件工程混淆。

## 15. 面包屑

在详情页面显示：

```text
分类名称 / 网站名称 / 账号名称
```

- 分类和网站可点击返回。
- 面包屑不显示用户名或密码。
- 窄窗口可只显示当前页面和返回按钮。

## 16. 空状态

| 状态 | 主文案目标 | 主操作 |
| --- | --- | --- |
| 新保险库 | 说明数据仅保存在本地 | 创建分类 |
| 空分类 | 尚无网站 | 添加网站 |
| 无账号网站 | 网站下尚无账号 | 添加账号 |
| 搜索无结果 | 没有匹配项 | 清除或修改搜索 |
| 回收站为空 | 没有已删除内容 | 返回分类 |

## 17. 权限与状态可见性

- 锁定时只显示解锁和恢复帮助。
- 已解锁时不持续显示主密码状态。
- 不支持的模块不显示空导航入口。
- 备份和恢复进行中显示进度并限制冲突操作。
- 数据损坏状态停止业务编辑，优先恢复。

## 18. 验收标准

- [ ] 用户能明确说出网站和账号的区别。
- [ ] 同一网站的多个账号不会表现为多个重复网站。
- [ ] 搜索结果可以定位回原始详情。
- [ ] 网站编辑与账号编辑分离。
- [ ] 锁定始终可发现。
- [ ] 删除影响在确认前可理解。
- [ ] 新用户能从空状态完成第一条账号创建。
- [ ] 常见查找复制流程不超过三次主要选择。
