## M4.1 本地排序与筛选

- 分类和网站默认采用稳定、可预测的名称排序；同名比较必须有稳定标识兜底。
- 网站列表提供最小筛选入口，复用现有安全搜索字段，不包含密码或敏感自定义字段。
- 多账号行保持现有折叠规则，排序不能丢失草稿输入或错误状态。
- 900×640 最低窗口和键盘操作继续可用。

退出条件：排序结果重启一致，筛选不会泄露敏感值，折叠与草稿状态回归通过。

完成证据（2026-08-02）：

- 分类、网站和账号统一按规范化名称升序，稳定 ID 作为同名兜底；Rust 仓储与浏览器原型语义一致。
- 现有顶部输入框在保险库视图中筛选当前分类，不新增重复搜索栏；只匹配网站名、账号名、用户名和邮箱。
- 密码和敏感自定义字段不参与筛选；筛选变化会清除网站批量选择，避免误操作隐藏行。
- 自动化覆盖同名稳定排序、敏感字段排除和草稿保持；虚构数据界面验证覆盖排序、用户名筛选、密码不匹配和草稿恢复。
- 900×640 下无页面横向溢出，筛选框与表格可见，控制台无错误。

## M4.2 离线密码生成器

- 由 Rust 使用操作系统安全随机源生成，不在前端使用 `Math.random()`。
- 首版参数只包含长度及大写、小写、数字、符号类别；设置合理上下限并保证至少选择一类。
- 生成结果默认隐藏，只能由用户明确显示、复制或填入当前密码输入框。
- 不写入日志、通知正文、搜索索引、Web Storage 或测试快照。
- 填入现有账号后仍需用户点击保存，不自动持久化。

退出条件：字符类别、长度边界、随机源调用、敏感面扫描和键盘流程均有测试证据。

完成证据（2026-08-02）：

- 桌面命令使用 Rust `OsRng.try_fill_bytes` 和拒绝采样，不依赖 `Math.random()`，随机源不可用时返回稳定错误。
- 生成长度限制为 8–128，可选择大小写字母、数字和符号，并保证每个已选类别至少出现一次。
- 生成器只把结果填入当前密码框，默认保持隐藏，不写入通知或日志，也不会自动保存账号。
- 浏览器开发原型使用 Web Crypto，以便仅用虚构数据进行界面测试；生产桌面路径仍由 Rust 命令生成。
- Rust 覆盖长度、类别和错误边界；前端覆盖参数传递、隐藏填入、不自动保存和关闭后焦点返回。

## M4.3 回收站批量管理

- 支持选择多个已删除对象并批量恢复。
- 支持选择后永久删除，并明确显示对象数量、不可恢复后果和备份建议。
- 永久删除采用数据库逻辑删除/物理行删除语义，不宣称能够可靠擦除 SSD、文件系统快照或备份中的历史数据。
- 批量操作必须原子提交；失败时不得只处理部分选择。

退出条件：混合对象、空选择、失败回滚、焦点顺序和确认数量回归通过。

完成证据（2026-08-02）：

- 批量恢复按“分类 → 网站 → 账号”排序，在单一事务中完成；父对象不可用或任一批次异常时整体回滚。
- 永久删除会物理删除所选实体树，并清理由该树关联的其他删除批次；空选择和超过 500 个输入被拒绝。
- 界面只操作明确勾选项，确认框显示准确数量，并提示子项范围、不可恢复、加密备份建议和非 SSD 安全擦除边界。
- 自动化覆盖父子混合恢复、失败全回滚、连带永久删除、空选择、确认数量和焦点返回；Rust 共 32 项测试通过。
- 使用两个虚构分类完成浏览器批量恢复回归：确认内容、取消焦点返回、列表原子更新、非空页面和零控制台警告/错误均通过。

- 测试或验收需要真实账号、真实密码或来源不明数据。
