# ADR-013：取消锁定设计并改用普通 SQLite（已被部分取代）

> 状态：存储选择已由 ADR-014 取代；“不再添加锁定设计”继续有效
>
> 决定日期：2026-08-01

当前实现见 [ADR-014](12-ADR_DPAPI_SQLCIPHER_AUTO_OPEN.md)：数据库恢复 SQLCipher 加密，密钥由 Windows DPAPI 自动保护，但仍没有主密码、锁定或解锁功能。

## 决定

项目删除整个锁定与解锁功能，不再设计替代锁屏能力。删除范围包括：主密码创建与验证；手动、自动、失焦和 Windows 生命周期锁定；Argon2id KDF、KEK/DEK 包装、加密安全头和 SQLCipher；以及依赖锁定状态的设置、恢复入口和测试。

桌面端改用 `rusqlite` 的普通 bundled SQLite，活动文件名为 `password-manager.db`。应用启动时直接创建或打开数据库。备份是普通 SQLite 副本，并使用 SHA-256 清单检测意外损坏或替换；摘要不提供保密性或攻击者认证。

## 数据兼容

- 不迁移现有 `vault.db`、`vault.header.json` 或旧加密备份。
- 新实现使用不同文件名和 `plaintext-backups` 目录，避免把旧格式误判为新数据库。
- 当前均为虚构测试数据，因此不提供旧数据导入工具。

## 后果

- 数据库与备份在磁盘上可直接读取。
- Windows 登录、NTFS 权限和设备自身安全成为唯一外部访问边界；应用不声称提供静态保密性。
- 项目不得发布为可安全保存真实秘密的密码管理器。
- 剪贴板条件清理、CSP、最小权限、输入校验、事务、备份摘要和安装包替换保护继续保留。

## 被取代的决定

ADR-007、ADR-009、ADR-010、ADR-012 以及 M3.2/M3.3/M3.4 中关于加密、KDF 和锁定的当前产品方向均由本决定取代。相关文件只作为历史实现记录保留。
