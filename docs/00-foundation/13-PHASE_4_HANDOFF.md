## 2. 不可改变的产品决定

- 保险库继续使用 Windows 当前用户 DPAPI 保护随机 SQLCipher 密钥，并在启动时自动打开。
- 不提供主密码、锁定、解锁、自动锁定、生物识别或锁屏联动功能。
- 不读取、迁移、覆盖或删除来源不明、旧明文或旧主密码测试保险库。
- 不新增云同步、浏览器扩展、团队共享、移动端或后台联网能力。
- 不通过在线服务获取网站图标，也不增加非必要 Tauri 权限。

## 3. M4 目标

M4 聚焦单机日常使用效率，不改变现有加密文件对和备份格式：

1. 统一现行文档，删除仍把主密码、锁定或解锁列为当前需求的冲突描述。
2. 为分类、网站和账号提供明确、稳定的本地排序与筛选能力。
3. 提供完全离线的密码生成器，并确保生成值不进入日志、搜索索引或默认界面明文。
4. 完善回收站的选择、批量恢复和永久删除流程；永久删除不宣称等同于介质安全擦除。
5. 在当前 Windows 上完成键盘、可访问性、升级安装和安全回归，冻结下一候选版本。

## 4. 明确延期

- 跨 Windows 用户或跨设备的可携带加密导出/导入。
- 明文 CSV/JSON 导出和第三方密码管理器导入。
- 标签、收藏、多保险库、附件、模板和自定义插件。
- 自动更新、代码签名、公开 GitHub Release 和公开仓库治理。

这些能力需要独立的数据格式、安全或发布决策，不在 M4 中顺带实现。

## 5. 退出条件

- 当前有效规范不再要求主密码或任何锁定功能。
- 新增能力不修改现有 SQLCipher/DPAPI 文件格式，不增加联网权限。
- 排序、筛选、密码生成和回收站批量操作具有自动化测试与 Windows 人工证据。
- 前端、Rust/SQLCipher/DPAPI、npm audit、RustSec、生产构建和敏感面门禁通过。
- 候选安装包只使用虚构数据完成首次安装、覆盖安装和重启验证。
