# 第五阶段 M5 执行计划

> 目标：在不改变 DPAPI/SQLCipher 存储边界的前提下，完成账号详情与灵活字段闭环
>
> 状态：M5.0–M5.5 完成 / `0.4.0-beta.2` 最终候选已冻结 / 远程 CI 已通过 / 仅虚构测试数据

## M5.0 基线与范围冻结

- 修正 README 的开发阶段，同步路线图、功能清单和验收文档。
- 冻结可选主邮箱、可选备注、自定义字段类型、敏感属性和排序规则。
- 保持 ADR-014、文件对、备份格式、无锁定和无联网边界不变。

退出条件：现行文档明确邮箱与备注语义，不再把已完成的 P0 字段功能标记为“已定义”。

## M5.1 账号详情编辑器

- 在紧凑账号行中提供明确的“编辑账号详情”图标操作。
- 详情对话框编辑账号名称、用户名、密码、可选主邮箱和可选备注。
- 密码默认隐藏，未编辑敏感值使用 `keepExistingValue` 保留，生成器填入后仍需显式保存。
- 关闭、取消和保存后返回原触发按钮。

完成证据：详情入口、固定系统字段、敏感值保留和 Escape 焦点返回已由前端自动化覆盖。

## M5.2 自定义字段管理

- 支持新增、编辑、删除自定义字段。
- 支持单行文本、密码、邮箱、网址和多行文本类型。
- 支持敏感属性；密码类型强制敏感。
- 使用明确上移/下移操作管理顺序，重启后保持。
- 字段标签在账号内按 NFKC 规范化后唯一。

完成证据：前端覆盖新增、敏感属性与重排；Rust 仓储覆盖字段顺序、原子保存与失败回滚。

## M5.3 查看、复制与搜索安全语义

- 主邮箱固定为非敏感 `email` 系统字段，每账号最多一个，允许搜索和复制。
- 备注固定为非敏感 `multiline` 系统字段，不进入分类筛选或全局搜索。
- 自定义字段允许复制；敏感字段只在用户显式操作后显示。
- 复制通知只显示字段名称，不包含字段值。

完成证据：前端分类筛选、浏览器原型和 Rust SQL 搜索均只匹配账号名、用户名与主邮箱；测试明确证明备注与密码不匹配。
