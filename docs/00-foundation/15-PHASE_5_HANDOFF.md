# M5 账号详情与灵活字段交接

> 最后更新日期：2026-08-03
>
> 状态：M5.0–M5.5 已完成；`0.4.0-beta.2` 本地候选已冻结

## 1. 基线

- GitHub `main` 的 M4 合并基线：`4899846`。
- M4 最终界面修正版：`0848684fd3b65fac40016dc99729e7db1b4837e4`。
- M4 内部候选：`0.3.0-beta.1`。
- M5 继续只使用明确标记的虚构测试数据。

## 2. 不可改变的产品边界

- 继续由 Windows 当前用户 DPAPI 保护随机 SQLCipher 密钥，启动时自动打开。
- 不提供主密码、锁定、解锁、自动锁定、生物识别或锁屏联动。
- 不修改现有 DPAPI/SQLCipher 文件对和加密备份格式。
- 不新增云同步、遥测、图标请求或其他后台联网能力。

## 3. M5 决策

- 账号行保留名称、用户名和密码的紧凑快速编辑，完整字段管理进入独立账号详情对话框。
- 主邮箱是可选系统字段；每个账号最多一个，固定为非敏感 `email` 类型，允许搜索和复制。
- 备注是可选系统字段；固定为非敏感 `multiline` 类型，使用固定多行编辑区，不进入搜索索引。
- 自定义字段支持单行、密码、邮箱、网址和多行类型，支持敏感属性与显式上下移排序。
- 自定义字段不进入搜索索引；敏感字段默认隐藏，未编辑时必须保留原值。
- 账号和全部字段始终在单一数据库事务中保存。
- 首次点击窗口关闭按钮时询问“关闭程序”或“最小化至托盘”；选择保存为默认行为，设置中可改为每次询问、最小化至托盘或关闭程序。
- 托盘双击恢复并聚焦主窗口；右键菜单提供打开和明确退出。托盘驻留不等同于锁定，保险库在当前 Windows 用户会话中仍可访问。

## 4. 明确延期

- 标签、收藏和组合筛选。
- CSV/JSON 明文导入导出和第三方密码管理器迁移。
- 多保险库、附件、深色主题和联网网站图标。
- 正式代码签名、独立安全评审和公开发布批准仍是独立发布治理项。

## 5. 退出条件

- 完成账号详情、邮箱、备注和自定义字段全闭环。
- 邮箱唯一性、备注非索引、敏感值保留和字段排序有自动化证据。
- 编辑、复制、显示/隐藏、密码生成和焦点返回具有键盘验收证据。
- 前端、Rust/DPAPI/SQLCipher、npm audit、RustSec、生产构建和敏感面门禁通过。
- 版本统一为 `0.4.0-beta.2`，生成 Windows NSIS 内部候选并记录 SHA-256。
