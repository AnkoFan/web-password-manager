## 长期候选

- 密码生成器
- 导入和明文导出风险流程
- 多保险库
- Windows Hello 快速解锁
- 附件、API Key、SSH Key 和许可证模板
- macOS 与 Linux

云同步、浏览器扩展、动态插件、团队共享和移动端均不属于当前路线范围；
若未来考虑，必须独立立项和重新进行威胁分析。

## 阶段规则

- 每一阶段以可运行、可测试的结果结束。
- 安全关键功能未验证前不宣称可保存真实秘密。
- 新功能先写清数据和模块边界，再接入主程序。
- 阶段内发现架构风险时优先修正，不为赶版本隐藏已知问题。
