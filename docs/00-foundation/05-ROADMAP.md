# 开发路线图

> 状态：M3、M4 已完成；`0.3.0-beta.1` 内部候选已冻结
>
> 全程仅使用虚构测试数据。

## 已实现功能

- [x] React + TypeScript + Tauri Windows 桌面骨架。
- [x] 分类、网站、多账号、系统/自定义字段和领域约束。
- [x] 搜索、敏感字段遮挡/显示/复制和网址打开。
- [x] 级联软删除、回收站和批次恢复。
- [x] 剪贴板条件定时清理。
- [x] 键盘、Narrator、缩放、高对比度、焦点和错误状态验收。
- [x] CI、RustSec、npm audit、CSP、最小权限和生产包扫描。
- [x] 删除主密码以及全部锁定/解锁界面和生命周期监听。

## M3 完成记录

1. [x] 核对 `main` 与 `m2.6-internal`，冻结虚构数据规则。
2. [x] 普通 SQLite 无锁定版本完成并通过本地/远程回归，作为短期产品决策记录。
3. [x] 冻结 ADR-014：DPAPI 保护随机 SQLCipher 密钥，继续自动打开且无锁定功能。
4. [x] 实现新文件对、完整性边界、DPAPI/SQLCipher 打开与加密备份恢复。
5. [x] 更新界面与规范，完成浏览器渲染、键盘和可访问性回归。
6. [x] 构建 Windows 测试安装包，验证首次启动、重启、文件头、备份恢复和旧测试文件不迁移。
7. [x] 冻结 `0.2.0-beta.1` 候选，重新生成安装包并记录最终 SHA-256。
8. [x] 一次性提交推送，通过 Frontend、Rust/SQLCipher/DPAPI 与 RustSec 门禁后合入 `main`。

## 不进入当前 M3

- 任何主密码、锁定、解锁、自动锁定或生物识别入口。
- 云同步、团队共享、浏览器扩展和移动端。
- 真实凭据迁移；旧明文及旧加密测试库均不迁移。

## M4 完成记录

1. [x] 统一现行规范，删除仍把主密码、KDF、锁定和解锁列为当前需求的冲突描述。
2. [x] 实现稳定的本地排序与安全字段筛选，不改变现有加密文件格式。
3. [x] 实现由 Rust 安全随机源驱动的离线密码生成器。
4. [x] 完善回收站批量恢复和永久删除，并明确非安全擦除边界。
5. [x] 完成 Windows 回归并冻结 `0.3.0-beta.1` 候选。

最终界面修正版提交为 `0848684fd3b65fac40016dc99729e7db1b4837e4`。仅使用虚构数据完成排序、筛选、密码生成、回收站批量操作、账号行固定输入尺寸和图标操作按钮验收；GitHub Actions CI `30778809134` 的 Frontend、Rust/DPAPI/SQLCipher 与 RustSec 检查全部通过。

详细范围和门禁见 [M4 交接](13-PHASE_4_HANDOFF.md) 与 [M4 执行计划](14-PHASE_4_EXECUTION_PLAN.md)。

## 不进入当前 M4

- 主密码、锁定、解锁、自动锁定、生物识别或 Windows 生命周期锁定。
- 云同步、团队共享、浏览器扩展、移动端和在线网站图标。
- 跨设备导入导出、明文导出、标签、收藏、多保险库和附件。
