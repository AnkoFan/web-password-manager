# 开发路线图

> 状态：M1、M2 历史增量完成 / M3 按 2026-08-01 产品决定重新排序
>
> 所有阶段仅使用虚构测试数据。

## 已完成的历史功能

- [x] React + TypeScript + Tauri Windows 桌面骨架。
- [x] 分类、网站、多账号、系统字段、自定义字段和领域约束。
- [x] 搜索、敏感值遮挡/显示/复制、网址打开。
- [x] 级联软删除、回收站和批次恢复。
- [x] 剪贴板条件定时清理。
- [x] 本机备份、验证、恢复和安装/卸载路径。
- [x] 键盘、Narrator、缩放、高对比度、对话框焦点与错误状态验收。
- [x] CI、RustSec、npm audit、CSP、最小权限和生产包扫描。
- [x] 曾实现并测试 SQLCipher、主密码、KDF、锁定及 Windows 生命周期联动；现已按 ADR-013 从产品中删除。

## 暂不进入当前 M3

- 云同步、遥测、浏览器扩展、团队共享和移动端。
- 密码生成器、导入导出、多数据库和附件。
- 任何新的锁定、解锁、主密码、生物识别或加密设计。

## 发布规则

- 明文存储警示必须在 README、设置页和发布说明中一致可见。
- 出现真实凭据、来源不明数据或无法确认已清理的测试产物时停止发布。
- 普通 SQLite 版本不能宣称安全保存真实秘密。
