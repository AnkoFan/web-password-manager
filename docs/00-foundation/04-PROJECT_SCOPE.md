# 项目范围

> 用途说明：明确项目当前和长期做什么、不做什么，以及 MVP、第一版正式发布和未来方向之间的边界。
>
> 状态：初稿 / 待评审
>
> 最后更新日期：2026-07-30

## 1. 范围声明

本项目当前范围是一款完全本地运行的桌面账号与敏感信息管理工具。第一阶段围绕网站、多个账号、灵活字段、搜索和安全使用建立最小闭环；长期可以扩展更多信息类型，但不在第一阶段实现云平台、团队系统或浏览器自动填充生态。

本文件定义产品边界，不替代详细 PRD、MVP 清单、安全设计或技术架构。

## 2. 核心用户任务

项目必须优先支持以下用户任务：

1. 创建或打开自己的本地保险库。
2. 使用主密码解锁保险库。
3. 建立分类并添加网站。
4. 在同一网站下保存多个不同用途的账号。
5. 为账号保存用户名、密码、邮箱、备注及任意自定义字段。
6. 通过分类或搜索快速找到所需信息。
7. 显示或隐藏敏感字段。
8. 一键复制所需字段。
9. 使用系统默认浏览器打开网站。
10. 锁定保险库并在下次启动时重新解锁。

如果某项工作不能改善这些核心任务或其安全性，应降低其第一阶段优先级。

## 3. MVP 范围

MVP 用于验证核心价值，不等同于可立即公开发布的成熟版本。

### 3.1 MVP 必须包含

#### 保险库与本地存储

- 在本地创建一个保险库。
- 设置并验证主密码。
- 对需要保护的持久化数据进行加密。
- 支持解锁、手动锁定和重新打开。
- 应用关闭后数据可以正确保存并再次读取。
- 错误密码不能通过正常应用流程读取保险库内容。

具体加密方案必须在安全设计中确定，不在本文件中提前指定。

#### 分类

- 新建、重命名和删除分类。
- 查看某分类下的网站。
- 删除包含网站的分类时必须给出明确处理方式，禁止静默丢失数据。

#### 网站

- 新建、查看、编辑和删除网站。
- 保存网站名称和主网址。
- 一个网站下可以拥有多个账号。
- 使用系统默认浏览器打开经过验证的网址。

#### 账号

- 新建、查看、编辑和删除账号。
- 使用账号名称区分私人、工作、测试等不同身份。
- 保存常用基础字段。
- 敏感字段支持显示和隐藏。
- 删除账号前需要明确确认。

#### 自定义字段

- 每个账号可以添加多个自定义字段。
- 字段至少包含名称、值、排序和敏感属性。
- 自定义字段可以编辑、删除、显示或隐藏、复制。
- 不为特定网站硬编码专属字段。

#### 搜索

- 支持从全局入口搜索网站名称、账号名称和非敏感标识字段。
- 搜索结果能够定位到对应网站和账号。
- 敏感字段是否参与索引必须经过安全和性能评审。

#### 复制与打开

- 支持复制用户名、密码、网址和自定义字段。
- 复制成功后提供不包含实际内容的提示。
- MVP 至少预留剪贴板自动清除配置；公开试用前必须完成安全行为。
- 支持使用系统默认浏览器打开网址。

### 3.2 MVP 可以简化

- 第一阶段只支持一个本地保险库。
- 第一阶段优先支持 Windows。
- 分类排序可以先采用简单规则。
- 网站图标可以使用默认图标，不要求联网下载 Favicon。
- 搜索可以先实现本地基础匹配，不要求复杂语法。
- 界面主题可以先完成一个稳定主题。
- 模块采用内部清晰边界，不要求动态安装和卸载。

## 4. 第一版正式发布范围

在 MVP 核心闭环稳定后，首个正式公开版本还应考虑：

- 自动锁定及合理的默认值。
- 剪贴板定时清除与平台限制说明。
- 加密备份、恢复和恢复验证。
- 数据库版本与迁移机制。
- 收藏和标签的基础能力。
- 搜索筛选、排序和空状态。
- 数据损坏、密码错误和迁移失败的区分处理。
- 完整的安全测试、恢复测试和发布检查。
- 用户可理解的安装、使用、备份和安全说明。
- 明确的开源许可证和漏洞披露流程。

是否将导入导出、密码生成器和深色主题纳入首个正式版本，由 PRD 和路线图评审决定。

## 5. 当前项目范围内，但非第一阶段

以下能力符合长期定位，但默认延后：

- 多保险库。
- 字段模板和网站模板。
- 密码生成器。
- 高级标签和动态集合。
- 本地附件。
- API Key、许可证和服务器信息专用模板。
- 更完善的数据导入导出。
- macOS 和 Linux 支持。
- 可选的动态插件机制。
- 便携版或其他安装形式。

这些能力必须分别经过需求、安全、数据和模块评审，不因出现在此处就视为已经承诺。

## 6. 明确不在当前范围

### 6.1 云端与协作

- 官方云端账号系统。
- 默认云同步。
- 团队共享保险库。
- 企业组织、角色和权限管理。
- 在线管理后台。

### 6.2 浏览器和移动端

- 浏览器扩展。
- 自动填充。
- 自动捕获登录表单。
- Android 或 iOS 应用。

### 6.3 高复杂度安全能力

- 硬件安全密钥集成。
- 生物识别解锁。
- 多人密钥分片。
- 企业密钥托管。
- 远程擦除。

这些能力可能在未来重新评估，但不能在当前架构中假装已经支持。

### 6.4 非产品目标

- 不作为云密码服务。
- 不作为团队协作平台。
- 不作为浏览器。
- 不作为通用文件加密工具。
- 不自行创造新的密码学算法。
- 不承诺能够在用户忘记主密码后绕过安全机制恢复数据。

## 7. 数据范围

### 7.1 第一阶段核心层级

```text
保险库
└─ 分类
   └─ 网站或服务
      └─ 一个或多个账号
         └─ 基础字段与自定义字段
```

标签和收藏是横向组织方式，不应取代主要数据关系。

### 7.2 网站级数据

预计包括：

- 名称。
- 主网址。
- 说明或图标引用。
- 分类关系。
- 创建和更新时间等元数据。

### 7.3 账号级数据

预计包括：

- 账号显示名称。
- 用户名、邮箱、密码和备注等基础字段。
- 任意数量的自定义字段。
- 收藏或标签关系。
- 创建和更新时间等元数据。

最终字段由数据模型和实体定义文档确定。

## 8. 平台与运行边界

- MVP 首要目标平台：Windows。
- 长期目标：评估 Windows、macOS 和 Linux。
- 核心功能应离线运行。
- 当前不要求 Docker 作为桌面应用运行方式。
- Docker 未来只在确有需要时用于开发环境、文档站或辅助服务。
- 当前候选技术栈已经确定为 Tauri 2、Rust、React、TypeScript、Vite、SQLite 与 SQLCipher；在 Windows 安装和 SQLCipher 原型通过前仍可调整。

## 9. 隐私与联网边界

- 核心账号管理不依赖网络。
- 默认不上传保险库、账号、字段、使用行为或崩溃数据。
- 网站图标等任何未来联网功能必须可关闭，并说明访问目标和数据内容。
- 打开网址属于用户主动触发的外部操作。
- 依赖检查、更新检查等开发或发布能力不得被混同为账号数据同步。

## 10. 发布边界

只有满足以下条件，项目才适合从内部 MVP 转为公开试用：

- 已完成并评审威胁模型和加密设计。
- 关键安全实现经过测试，且没有已知的高风险绕过路径。
- 备份和恢复流程经过真实恢复验证。
- 数据库升级失败时存在可理解的恢复方案。
- 日志、错误和测试数据不包含真实敏感信息。
- 用户能够理解主密码遗忘和数据恢复的限制。
- 已选择许可证并建立安全漏洞报告方式。

## 11. 范围变更规则

新增需求进入某个版本前必须说明：

- 解决的用户问题。
- 优先级和目标版本。
- 所属模块。
- 对数据模型和迁移的影响。
- 对安全、隐私和联网边界的影响。
- 验收标准和测试方式。
- 是否会推迟当前核心里程碑。

范围变更应记录在功能清单、路线图或架构决策记录中。
