# M6 纯界面重构执行计划

> 目标：在不改变程序核心、存储与业务语义的前提下，重建一致、清晰且适合日常使用的 Windows 桌面界面
>
> 状态：M6.0 进行中；概念确认前不进入实现

## M6.0 审计、概念与规格冻结

- 保存主工作区、账号详情和设置页的现状参考图。
- 生成完整桌面主界面与账号详情视觉概念，不以局部样式板代替完整界面。
- 从确认稿提取颜色、排版、间距、圆角、边框、阴影、图标和动效令牌。
- 冻结允许出现的文案、页面结构、组件族和响应式降级规则。

退出条件：概念获得确认，且没有新业务功能、虚假状态或无法由现有 React 结构实现的元素。

## M6.1 设计令牌与应用外壳

- 统一背景、表面、正文、弱化文字、边框、主色、危险色和焦点环。
- 建立 UI chrome 与内容文字的明确字号、字重和行高。
- 重构品牌区、主导航、分类导航、顶部搜索和页面标题区。
- 保留现有键盘快捷键、焦点返回和高对比度语义。

退出条件：应用外壳在空状态、保险库、回收站和设置之间保持同一布局与导航语义。

## M6.2 三栏保险库工作区

- 第一栏保留主导航和分类；第二栏展示所选分类的网站；第三栏展示所选网站的账号。
- 将添加、重命名、删除和批量操作放入稳定工具栏或更多菜单，避免单行图标堆叠。
- 账号列表保留名称、用户名、密码隐藏状态、复制、显示、打开、保存和详情入口。
- 空状态明确呈现“分类 → 网站 → 账号”下一步，不新增引导流程或持久化状态。

退出条件：1280×720 无水平滚动，网站与账号父子关系清楚，现有创建、保存、复制、显示、生成、打开和删除路径全部可达。

## M6.3 详情、搜索、回收站与设置

- 账号详情按基础信息、邮箱与备注、自定义字段分区，统一字段操作和敏感状态表达。
- 搜索结果复用网站与账号列表组件，保持当前安全搜索范围。
- 回收站复用页面标题、选择工具栏、列表和危险确认组件。
- 设置改为单列分区：安全边界、剪贴板、关闭行为、本机备份；不新增主题或锁定设置。

退出条件：所有页面共享同一设计系统，现有自动化所依赖的可访问名称和行为保持稳定或同步更新测试。

## M6.4 响应式与可访问性收口

- 900×640 下将三栏压缩为分类窄栏、网站栏和账号栏；必要时使用可返回的单栏层级，不隐藏核心操作。
- 450×640 下使用单栏逐级导航，弹窗改为适配窄屏的全高表单。
- 验证键盘顺序、Escape、焦点返回、Narrator、200% 缩放、高对比度和 `prefers-reduced-motion`。
- 使用应用内浏览器逐状态对照确认稿，记录至少五项视觉比对证据。

退出条件：桌面和窄屏无裁切、横向溢出、不可见主操作或浏览器默认控件排版。

## M6.5 回归与候选发布

- 运行前端、Rust/DPAPI/SQLCipher、npm audit、RustSec、生产构建和敏感面门禁。
- 仅使用虚构数据完成 Windows 安装、升级和数据保留回归。
- 根据实际变更决定版本号；不预先承诺固定发布日期或后续 M7。

退出条件：视觉确认、功能回归、Windows 候选和远端 CI 全部通过后，才允许合并和预发布。
