# 当前安全模型

> 状态：Windows DPAPI + SQLCipher 自动打开；仅虚构测试数据

## 提供的控制

- SQLCipher 静态数据库加密与完整性检查。
- 当前用户范围 DPAPI 自动保护随机数据库密钥。
- Tauri CSP、最小权限、无遥测和无远程脚本。
- 列表/搜索响应最小化，敏感字段默认遮挡。
- 剪贴板条件定时清理。
- 加密备份、文件长度/SHA-256、恢复前验证与失败回滚。
- 依赖审计、生产包扫描和安装包替换保护。

## 明确限制

- 应用没有锁定状态，启动后自动显示数据。
- Windows 锁屏、睡眠、切换用户或切换应用不会触发应用锁定。
- 当前用户上下文中的恶意程序可能调用 DPAPI；管理员、内核攻击者或运行期内存读取不在静态加密防护范围。
- 屏幕录制、旁观、剪贴板历史、第三方剪贴板工具和系统转储可能保留副本。
- DPAPI 备份通常不能跨 Windows 用户或缺少原用户密钥的设备恢复。
- 当前构建未正式签名，仍不得用于真实秘密。

## 数据规则

所有测试只使用 `TEST-ONLY` 虚构身份、保留示例域名和虚构字段值。不迁移或删除此前的明文/旧加密测试数据。
