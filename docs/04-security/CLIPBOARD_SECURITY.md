# 剪贴板安全

> 状态：M2.5 已实现并完成内部回归
>
> 最后更新日期：2026-07-30

## 安全目标

- 密码、Token 和网址均由 Rust 命令写入系统剪贴板。
- 复制提示、日志和错误消息不包含实际内容。
- 默认 30 秒后尝试清理，可配置范围为 5–300 秒。
- 只清理由本应用本次写入且尚未被用户替换的内容。

## 实现

Rust 写入后立即计算 SHA-256 摘要，只把摘要和清理期限交给后台线程。到期后在线程中读取当前剪贴板，计算摘要并进行常量长度比较；只有匹配时才调用清理。读取到的临时字符串在比较后调用 `zeroize`。

连续复制 A、B 时，A 的计时器不会清理 B；用户随后复制其他应用内容时也不会被覆盖。锁定保险库不会取消已登记的清理任务。

浏览器开发原型使用等价的内容比较，仅用于界面测试；生产桌面端不在定时任务中保留原始秘密字符串。

## 限制

- Windows 剪贴板历史、云剪贴板和第三方剪贴板工具可能在清理前保存副本。
- 操作系统或其他进程拒绝读取时，本次条件清理安全失败，不会覆盖未知内容。
- 不能保证 WebView、插件或操作系统内部副本立即从内存消失。

## 验收

- [x] 原内容未变化时到期清空。
- [x] 用户替换内容后不清空。
- [x] 连续复制使用各自摘要和期限。
- [x] 前端不再拥有直接写剪贴板权限。
- [x] 通知和日志不显示秘密。
