# 威胁模型

> 用途说明：识别本地密码管理器的攻击者、数据流、主要威胁、控制措施、残余风险和测试要求。
>
> 状态：M3 回归完成 / 已按 ADR-014 自动打开模型更新
>
> 最后更新日期：2026-07-31

## 1. 范围

本威胁模型针对：

- Windows 本地桌面应用。
- 单用户、单保险库。
- 一个 `Setup.exe` 安装入口。
- 无服务器、无云同步、无浏览器扩展。
- DPAPI + SQLCipher 自动打开保险库、剪贴板和本地加密备份。

不包含远程 API、团队共享和移动端威胁。

## 2. 攻击者

| 攻击者 | 能力 |
| --- | --- |
| 获得保险库文件的人 | 可复制 SQLCipher 数据库和 DPAPI 密钥文件并离线分析 |
| 获得丢失设备的人 | 可读取用户文件，可能尝试登录 Windows |
| 同一 Windows 账号下的普通程序 | 可能读取剪贴板、用户可访问文件和窗口内容 |
| 篡改下载文件的攻击者 | 尝试替换安装包或发布文件 |
| 恶意导入文件提供者 | 构造损坏、超大或异常数据 |
| 低权限本地攻击者 | 尝试利用文件权限、路径或协议处理漏洞 |
| 控制下载或发布渠道的攻击者 | 替换安装包、校验值、更新说明或旧版本链接 |
| 能终止进程或耗尽本机资源的攻击者 | 在迁移、备份或替换窗口制造部分状态 |

具有管理员、调试或内核权限，或能在同一 Windows 用户上下文运行恶意程序的攻击者属于明确残余风险。

## 3. 数据流

```mermaid
flowchart TD
    CSPRNG["Windows CSPRNG"] --> KEY["随机数据库密钥"]
    KEY --> DPAPI["当前用户 DPAPI 密文"]
    DPAPI --> OPEN["启动时自动解开"]
    OPEN --> DB["SQLCipher 数据库"]
    DB --> UI["界面显示"]
    DB --> SEARCH["安全字段搜索"]
    DB --> CLIP["Windows 剪贴板"]
    DB --> URL["默认浏览器"]
    DB --> BACKUP["加密备份"]
```

敏感数据越过边界时必须有明确用户动作或受控服务调用。

## 4. 风险等级

| 等级 | 解释 |
| --- | --- |
| 严重 | 可直接读取大量秘密、绕过 Windows 用户保护或破坏全部数据 |
| 高 | 可读取单个秘密、持久泄露或导致难以恢复的数据损坏 |
| 中 | 需要较强前置条件、泄露有限元数据或造成可恢复故障 |
| 低 | 影响有限、容易发现且可恢复 |

公开版本存在未处理的严重或高风险问题时不得发布。

## 5. 主要威胁

### T-001 保险库文件被复制

- 风险：严重。
- 场景：攻击者获得数据库和安全头，在其他设备离线分析。
- 控制：随机数据库密钥、SQLCipher 页面加密与完整性、当前用户 DPAPI 保护、文件对验证。
- 测试：文件中搜索不到已知秘密；DPAPI 不匹配、密钥篡改和数据库损坏均失败。
- 残余风险：攻击者控制同一 Windows 用户上下文时，DPAPI 不能建立额外隔离。

### T-002 当前 Windows 用户上下文被控制

- 风险：严重。
- 场景：恶意程序以相同 Windows 用户身份调用 DPAPI、读取应用文件、剪贴板、窗口或运行期内存。
- 控制：依赖 Windows 账号与设备保护、最小 Tauri 权限、敏感字段默认隐藏、条件剪贴板清理和准确风险说明。
- 不采用：应用主密码或本地失败次数锁定；ADR-014 明确选择自动打开模型。
- 残余风险：静态加密无法隔离已被控制的同一用户上下文。

### T-003 数据库篡改

- 风险：高。
- 场景：修改密文页面、头信息、对象关系或版本。
- 控制：数据库页完整性、密钥包装 AEAD、受认证的关键头字段、结构校验和事务。
- 测试：随机翻转头、包装密钥和数据库字节必须导致明确失败。

### T-004 回滚到旧保险库

- 风险：中。
- 场景：攻击者或误操作用旧副本替换当前文件。
- 控制：显示备份时间、版本和恢复确认；迁移前后保留明确恢复点。
- 残余风险：完全离线且无可信外部计数器时，无法可靠检测所有合法旧副本回滚。

### T-005 DPAPI 明文密钥进入日志或配置

- 风险：严重。
- 场景：调试输出、错误对象或崩溃报告包含数据库密钥或 DPAPI 解开后的材料。
- 控制：敏感类型、禁止调试格式、日志脱敏、测试扫描。
- 测试：崩溃路径、错误输出和诊断包中检索仅用于测试的密钥标记。

### T-006 数据密钥泄露

- 风险：严重。
- 场景：密钥被写入日志、临时文件、交换文件或长时间保留。
- 控制：仅在打开 SQLCipher 所需范围内保存、敏感容器、尽力清零、不序列化、不复制到 UI。
- 残余风险：高权限内存读取和操作系统换页。

### T-007 自动打开后的界面暴露

- 风险：高。
- 场景：应用启动后保险库自动可见，肩窥、屏幕捕获或仍打开的窗口暴露敏感信息。
- 控制：敏感字段默认隐藏、显示与复制必须明确触发、对象切换后恢复隐藏、文档披露无锁定边界。
- 测试：启动、对象切换、旧弹窗、显示与复制的默认遮挡和焦点行为。

### T-008 剪贴板泄露

- 风险：高。
- 场景：其他应用或剪贴板历史读取密码。
- 控制：用户主动复制、定时清除、条件清除、风险说明。
- 残余风险：复制后到清除前的窗口，以及系统或第三方历史记录。

### T-009 明文临时文件

- 风险：严重。
- 场景：数据库解密、恢复或导出时留下明文副本。
- 控制：数据库保持加密；恢复在受控临时路径；失败清理；普通操作不生成明文文件。
- 测试：创建、保存、搜索、备份和恢复后扫描应用目录及临时目录。

### T-010 搜索索引泄露

- 风险：高。
- 场景：建立用户名、Token 或密码的明文磁盘索引。
- 控制：MVP 只在解锁会话中搜索；秘密字段不持久化索引；锁定清理。

### T-011 危险网址协议

- 风险：高。
- 场景：恶意数据使用 `file:`、`javascript:` 或系统协议触发本地行为。
- 控制：只允许 `https` 和经提示的 `http`；解析后再调用系统；不执行命令字符串。
- 测试：危险协议、转义、空白和混淆输入。

### T-012 安装包被替换

- 风险：严重。
- 场景：用户下载到植入恶意代码的同名 `.exe`。
- 控制：HTTPS 发布渠道、代码签名、校验值、固定发布者身份、发布记录。
- 残余风险：用户忽略签名错误或从非官方渠道下载。

### T-013 依赖或构建链受损

- 风险：严重。
- 场景：第三方依赖、构建脚本或发布环境被植入恶意代码。
- 控制：锁定依赖、最小依赖、审查关键库、自动化构建、产物溯源和最小发布权限。

### T-014 恶意导入或备份文件

- 风险：高。
- 场景：超大字段、畸形版本、路径穿越、关系环或资源耗尽。
- 控制：大小限制、严格解析、版本检查、无脚本执行、临时位置验证、事务导入。

### T-015 数据库损坏或写入中断

- 风险：高。
- 场景：断电、磁盘满、杀进程或迁移失败。
- 控制：事务、WAL 策略评审、原子替换、迁移前备份、完整性检查。
- 测试：模拟磁盘满、异常关闭和字节损坏。

### T-016 卸载误删数据

- 风险：高。
- 场景：用户卸载应用时保险库被一并删除。
- 控制：卸载默认保留用户数据；删除数据使用独立确认流程。

### T-017 UI 注入或 WebView 内容执行

- 风险：严重。
- 场景：网站名、备注或字段值被当作 HTML 执行。
- 控制：框架默认文本转义、禁止渲染用户 HTML、严格内容安全策略、不开启不必要远程内容。
- 测试：脚本、HTML、SVG 和 URL 载荷作为普通文本显示。

### T-018 高权限恶意软件

- 风险：严重但超出可靠防护范围。
- 场景：管理员恶意软件读取键盘、进程内存或屏幕。
- 控制：减少敏感值默认显示、签名发布计划、最小权限和用户说明。
- 残余风险：无法在同一已受控操作系统内建立绝对隔离。

### T-019 文件对或 schema 降级

- 风险：严重。
- 场景：攻击者替换数据库或 DPAPI 文件、修改 schema 版本，诱导应用把不匹配或未来格式当作有效保险库。
- 控制：数据库/密钥文件对验证、DPAPI 当前用户绑定、SQLCipher 标记与完整性检查、未知 schema 安全拒绝。
- 测试：删除或替换任一文件、篡改 DPAPI blob、截断数据库并提高 schema；确认在业务写入前拒绝。

### T-020 迁移中断与双文件不一致

- 风险：高。
- 场景：进程终止、磁盘满、文件占用或断电发生在 schema 迁移和头替换之间。
- 控制：修改前持久迁移快照、数据库事务、v2 暂存验证、回滚头、启动残留恢复和父目录同步。
- 测试：对每个文件操作与事务边界注入失败，确认最后一个已验证组合可恢复。
- 残余风险：安全头和数据库仍是双文件；多重介质故障可能需要人工恢复迁移快照。

### T-021 崩溃转储、WebView2 缓存与临时目录残留

- 风险：高。
- 场景：主密码、字段值或页面内容进入 Windows 崩溃转储、WebView2 缓存或公共临时目录。
- 控制：不主动生成含敏感状态的诊断包、前端不持久化、迁移只用应用私有目录、发布前人工扫描。
- 测试：用唯一虚构标记执行异常退出和浏览流程，扫描缓存、转储与临时目录。
- 残余风险：管理员工具或第三方崩溃捕获程序可能在解锁时读取进程内存。

### T-022 升级、降级或卸载破坏数据

- 风险：高。
- 场景：旧版本打开新格式、覆盖安装中断，或卸载程序误删保险库。
- 控制：未知格式拒绝、单向迁移提示、迁移快照、安装与数据目录分离、卸载默认保留数据。
- 测试：`0.1.0` 到 beta 覆盖升级、旧版本打开 v2、失败升级、卸载保留与显式清理。

### T-023 发布身份与校验材料同时被替换

- 风险：严重。
- 场景：攻击者同时替换安装包和同一渠道的 SHA-256，用户无法发现。
- 控制：固定官方渠道、统一发布身份、正式代码签名、独立记录提交与产物哈希、最小发布权限。
- 残余风险：未配置受信代码签名前，SHA-256 只能检测意外损坏，不能单独证明发布者身份。

## 6. 不采用的控制

- 不使用联网服务器保存主密码验证结果。
- 不依赖失败次数锁定抵御离线攻击。
- 不把隐藏算法或文件格式当作安全措施。
- 不使用自签名证书让普通用户建立错误信任。
- 不把 Windows 登录密码或 DPAPI 作为唯一保险库主密钥，因为需要用户控制和备份可携带性。
- 不在 MVP 实现复杂反调试或代码混淆来代替密码学保护。

## 7. 隐私威胁

即使密码安全，以下信息泄露也可能伤害用户：

- 使用过哪些网站。
- 分类和账号名称。
- 账号数量。
- 更新时间和使用习惯。
- 搜索词。

因此这些元数据默认加密，不记录最近使用和搜索历史，不默认发送遥测。

## 8. 验证计划

| 类别 | 必须测试 |
| --- | --- |
| 离线文件 | 明文扫描、错误密码、参数篡改、密文篡改 |
| 会话 | 锁定、返回、快捷键、并发窗口、休眠 |
| 内存与日志 | 密钥不序列化、日志扫描、崩溃路径 |
| 剪贴板 | 复制正确性、定时清除、条件清除 |
| URL | 允许协议、危险协议、解析混淆 |
| 数据完整性 | 异常退出、磁盘满、迁移失败、损坏 |
| 发布 | 签名验证、校验值、依赖清单 |
| UI | 用户输入按文本渲染、CSP、无远程脚本 |
| 格式迁移 | v1/v2 兼容、规范 AAD、KDF 边界、故障注入、启动恢复 |
| 系统残留 | WebView2 缓存、临时目录、崩溃转储、剪贴板历史 |
| 安装生命周期 | 全新安装、覆盖升级、降级拒绝、卸载保留/清理 |

## 9. 评审触发条件

增加以下任一能力时必须重做相关威胁分析：

- 自动更新。
- 联网图标下载。
- 导入第三方密码库。
- 浏览器扩展或自动填充。
- 云同步。
- 多保险库。
- 生物识别或 Windows Hello 快速解锁。
- 动态插件。
- 附件。
