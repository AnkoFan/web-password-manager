# 敏感数据处理

> 用途说明：记录主密码、密钥、字段值、日志、WebView 和剪贴板的运行时处理规则。
>
> 状态：第一阶段已评审 / 公开使用控制待完善
>
> 最后更新日期：2026-07-30

## 1. 分类

| 类型 | 示例 | 持久化 | 默认界面 |
| --- | --- | --- | --- |
| 认证秘密 | 主密码 | 禁止 | 密码输入 |
| 密钥材料 | KEK、DEK | 仅包装后的 DEK | 不进入界面 |
| 秘密字段 | 密码、Token | SQLCipher 内 | 遮挡 |
| 私密数据 | 用户名、网址、备注 | SQLCipher 内 | 按需显示 |
| 安全元数据 | 盐、KDF 参数、nonce、包装 DEK | 安全头 | 不显示 |

所有业务内容都受保险库存储加密保护；`is_sensitive` 只控制运行时展示和复制，不代表其他字段可以明文落盘。

## 2. 主密码

- React 受控输入只在创建或解锁组件内保存。
- 不写入浏览器存储、URL、配置或日志。
- 通过单个受限 Tauri 命令传给 Rust。
- Rust 命令参数在完成后调用 `zeroize`。
- JavaScript 字符串、IPC 序列化和 WebView 内存可能产生无法可靠清零的副本，这是当前架构限制。
- 成功创建或解锁后组件被卸载；失败时输入暂时保留以便用户修正。

## 3. KEK 与 DEK

- KEK 和 DEK 使用 `Zeroizing<Vec<u8>>`。
- KEK 只存在于派生和包装/解包期间。
- DEK 用于打开 SQLCipher 后不保存为 Rust 会话字段。
- SQLCipher 内部仍会持有使用密钥所需的状态，关闭连接后由库释放。
- KEK、DEK 不实现序列化，不返回前端，不写入日志。
- SQLCipher `cipher_memory_security` 已启用，释放 SQLite/SQLCipher 分配器内存前会进行覆盖擦除；每次打开连接都会读回状态，验证失败即拒绝使用。
- Windows 构建定义 `OMIT_MEMLOCK`，避免 `VirtualLock` 配额失败通过 SQLCipher 日志递归导致栈溢出。因此当前实现提供增强擦除，但不声明数据库内存页被 OS 锁定或不会换出。

## 4. 数据库与安全头

- 数据库使用 SQLCipher 原始 256 位 DEK。
- 解锁时执行页面 HMAC 完整性检查、SQLite 逻辑完整性检查和保险库标记验证。
- 安全头读取上限为 64 KiB。
- 安全头不包含用户业务内容。
- 创建使用 `.creating` 文件并只在结构完成后移动为有效文件。
- 安全头与数据库是两个文件，不能实现真正的双文件原子提交；部分状态会进入恢复错误，不会被当作空保险库。

## 5. 前端和 IPC

- 不使用 `localStorage` 或 `sessionStorage` 保存主密码和业务秘密。
- 不使用 `dangerouslySetInnerHTML` 渲染用户数据。
- CSP 默认只允许应用自身资源和 Tauri IPC。
- 当前前端没有远程数据请求。
- 第二阶段列表接口不得返回秘密字段值；敏感值按显示或复制操作单独读取。

## 6. 日志与诊断

禁止：

- 主密码、KEK、DEK。
- 用户名、网址、字段值和搜索词。
- 完整请求 DTO 或解密对象。

当前代码没有记录上述内容。Debug 构建启用 Tauri 日志插件，但业务代码没有输出敏感参数。生产构建不启用该插件。

WebView2 自身会在应用数据目录产生缓存、历史和诊断数据库；应用不得向 WebView 导航包含秘密的 URL，也不得把秘密写入 Web Storage。

## 7. 显示与复制

- 密码和敏感字段默认遮挡。
- 显示必须由用户主动触发。
- 切换对象、锁定或重新解锁后恢复遮挡。
- 复制反馈不包含实际内容。
- 当前复制字符串会跨越 Rust、插件和 Windows 剪贴板，无法证明所有内部副本已立即清零。
- 桌面端复制后默认 30 秒执行条件清理；后台任务只保留 SHA-256 摘要，当前内容仍匹配时才清空。
- Windows 剪贴板历史与第三方工具仍可能保留副本，因此当前版本仍不能仅依赖定时清理保护真实秘密。

## 8. 测试规则

- 只使用明确标记的虚构秘密。
- 日志、临时目录和正式保险库执行已知字符串扫描。
- 错误消息不得包含输入值。
- 篡改、错误密码、超大安全头和锁定状态必须安全失败。
- 公开使用前增加崩溃路径、WebView 存储和剪贴板历史测试。

## 9. 验收

- [x] 主密码不写入项目配置和普通日志。
- [x] KEK、DEK 不返回 WebView。
- [x] 安全头大小受限。
- [x] 数据库和头文件不直接保存演示秘密明文。
- [x] 锁定后秘密命令被拒绝。
- [x] Windows 增强内存擦除策略完成首轮评审。
- [ ] Windows OS 页锁定或等价的防换出策略完成评审。
- [x] 剪贴板定时条件清理完成。
- [ ] WebView2 缓存、崩溃数据和存储经过自动扫描。
- [x] 自动锁定和窗口失焦/休眠进入锁定完成。
