# 敏感数据处理

> 用途说明：记录数据库密钥、字段值、日志、WebView 和剪贴板的运行时处理规则。
>
> 状态：M3 当前实现已同步 / 独立安全评审待完成
>
> 最后更新日期：2026-07-30

## 1. 分类

| 类型 | 示例 | 持久化 | 默认界面 |
| --- | --- | --- | --- |
| 平台保护材料 | DPAPI 保护的数据库密钥 | 独立密钥文件 | 不进入界面 |
| 数据库密钥 | 随机 256 位 SQLCipher 密钥 | 仅以 DPAPI 密文持久化 | 不进入界面 |
| 秘密字段 | 密码、Token | SQLCipher 内 | 遮挡 |
| 私密数据 | 用户名、网址、备注 | SQLCipher 内 | 按需显示 |
| 安全元数据 | 文件对版本、schema、完整性清单 | 数据库或备份清单 | 不显示 |

所有业务内容都受保险库存储加密保护；`is_sensitive` 只控制运行时展示和复制，不代表其他字段可以明文落盘。

## 2. DPAPI 与数据库密钥

- 随机数据库密钥只在 Rust 后端生成，不返回 React 或通过 IPC 序列化。
- 密钥只以 Windows 当前用户 DPAPI 密文持久化，不写入 URL、配置或日志。
- 打开时先验证数据库/密钥文件对，再由 DPAPI 解开并交给 SQLCipher。
- 文件对不完整、DPAPI 失败、数据库损坏或 schema 不兼容时安全停止，不创建或覆盖另一文件。
- Rust 中可控的临时密钥缓冲区在完成后尽力清零；SQLCipher 和操作系统内部副本仍属于残余风险。

## 3. SQLCipher 运行期状态

- 数据库密钥使用 `Zeroizing<Vec<u8>>` 等敏感容器。
- 密钥用于打开 SQLCipher 后不保存为可序列化的 Rust 会话字段。
- SQLCipher 内部仍会持有使用密钥所需的状态，关闭连接后由库释放。
- 数据库密钥不实现业务序列化，不返回前端，不写入日志。
- SQLCipher `cipher_memory_security` 已启用，释放 SQLite/SQLCipher 分配器内存前会进行覆盖擦除；每次打开连接都会读回状态，验证失败即拒绝使用。
- Windows 构建定义 `OMIT_MEMLOCK`，避免 `VirtualLock` 配额失败通过 SQLCipher 日志递归导致栈溢出。因此当前实现提供增强擦除，但不声明数据库内存页被 OS 锁定或不会换出。

## 4. 数据库与安全头

- 数据库使用 SQLCipher 原始 256 位 DEK。
- 打开时执行页面 HMAC 完整性检查、SQLite 逻辑完整性检查和保险库标记验证。
- 安全头读取上限为 64 KiB。
- 安全头不包含用户业务内容。
- 创建使用 `.creating` 文件并只在结构完成后移动为有效文件。
- 安全头与数据库是两个文件，不能实现真正的双文件原子提交；部分状态会进入恢复错误，不会被当作空保险库。

## 5. 前端和 IPC

- 不使用 `localStorage` 或 `sessionStorage` 保存业务秘密或数据库密钥。
- 不使用 `dangerouslySetInnerHTML` 渲染用户数据。
- CSP 默认只允许应用自身资源和 Tauri IPC。
- 当前前端没有远程数据请求。
- 第二阶段列表接口不得返回秘密字段值；敏感值按显示或复制操作单独读取。

## 6. 日志与诊断

禁止：

- 数据库密钥和 DPAPI 解开后的材料。
- 用户名、网址、字段值和搜索词。
- 完整请求 DTO 或解密对象。

当前代码没有记录上述内容。Debug 构建启用 Tauri 日志插件，但业务代码没有输出敏感参数。生产构建不启用该插件。

WebView2 自身会在应用数据目录产生缓存、历史和诊断数据库；应用不得向 WebView 导航包含秘密的 URL，也不得把秘密写入 Web Storage。

## 7. 显示与复制

- 密码和敏感字段默认遮挡。
- 显示必须由用户主动触发。
- 切换对象、组件重新挂载或应用重启后恢复遮挡。
- 复制反馈不包含实际内容。
- 当前复制字符串会跨越 Rust、插件和 Windows 剪贴板，无法证明所有内部副本已立即清零。
- 桌面端复制后默认 30 秒执行条件清理；后台任务只保留 SHA-256 摘要，当前内容仍匹配时才清空。
- Windows 剪贴板历史与第三方工具仍可能保留副本，因此当前版本仍不能仅依赖定时清理保护真实秘密。

## 8. 测试规则

- 只使用明确标记的虚构秘密。
- 日志、临时目录和正式保险库执行已知字符串扫描。
- 错误消息不得包含输入值。
- 文件篡改、DPAPI 不匹配、数据库损坏和不完整文件对必须安全失败。
- 公开使用前增加崩溃路径、WebView 存储和剪贴板历史测试。

## 9. 验收

- [x] 数据库密钥不写入项目配置和普通日志。
- [x] 数据库密钥不返回 WebView。
- [x] 安全头大小受限。
- [x] 数据库和头文件不直接保存演示秘密明文。
- [x] 文件对或 DPAPI 验证失败时秘密命令不可用且不覆盖文件。
- [x] Windows 增强内存擦除策略完成首轮评审。
- [ ] Windows OS 页锁定或等价的防换出策略完成评审。
- [x] 剪贴板定时条件清理完成。
- [ ] WebView2 缓存、崩溃数据和存储经过自动扫描。
- [x] 窗口失焦、休眠和锁屏不会产生未声明的应用锁定状态。
