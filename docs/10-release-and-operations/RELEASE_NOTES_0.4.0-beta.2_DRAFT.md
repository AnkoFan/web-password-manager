# WebPasswordManager 0.4.0-beta.2 发布说明草案

> 状态：本地候选已冻结，等待远程 CI 后发布为预发布版本
>
> 数据要求：仅使用虚构测试数据

## 本次新增

- 从紧凑账号行进入完整账号详情，统一编辑基础字段和自定义字段。
- 每个账号可保存一个可搜索、可复制的可选主邮箱。
- 每个账号可保存非敏感多行备注；备注不进入搜索索引。
- 自定义字段支持新增、编辑、删除、类型选择、敏感属性、复制和上下排序。
- 账号和全部字段继续在单一数据库事务中保存。
- 首次关闭窗口时可选择关闭程序或最小化至系统托盘，选择会保存并可在设置中调整。
- 双击托盘图标可以恢复并聚焦主窗口；托盘菜单提供打开和明确退出。

## 保持不变的安全边界

- 数据仅保存在当前 Windows 用户的本机目录；没有云同步或联网传输。
- SQLCipher 数据库密钥由 Windows DPAPI 绑定当前用户保护，应用启动后自动打开。
- 应用没有主密码、锁定或解锁功能。
- 最小化至托盘不是锁定或退出，保险库在当前 Windows 用户会话中仍保持可访问。
- 密码与敏感自定义字段默认隐藏，未编辑时不会在保存中被清空。
- 全局搜索和分类筛选只匹配网站、账号名、用户名和主邮箱，不匹配备注、密码或自定义字段。

## 已知限制

- 候选安装包没有正式代码签名，Windows 可能显示未知发布者提示。
- DPAPI 保护通常不能跨 Windows 用户或跨设备恢复。
- 当前用户上下文恶意程序、管理员、运行期内存读取、屏幕和剪贴板历史不由静态加密解决。
- 尚未完成独立安全评审；公开发布需项目所有者另行批准。
