# WebPasswordManager 0.2.0-beta.1 发布说明草案

> 状态：未获准发布的 M3 候选草案
>
> 更新日期：2026-08-01
>
> 在许可证、代码签名、最低设备与 Windows 人工验收、独立安全评审和仓库治理全部关闭前，本草案不构成发布公告。当前构建仍只能使用明确标记的虚构测试数据，不应用于保存真实秘密。

## 适用范围

- Windows 11 x64 当前用户、本地单用户保险库。
- 数据默认只保存在本机；不提供云同步、浏览器扩展、团队共享、遥测或自动更新。
- 候选版本只支持由用户主动运行、经过签名和哈希验证的 NSIS 覆盖安装。

## 主要变化

- 安全头 v2：固定 magic、保险库 ID、规范化 AAD、算法标识和有界 KDF 配置。
- v1 到 v2 的单向迁移：解锁成功后先创建并验证迁移前快照，再重新包装同一数据密钥；迁移失败时保留最后一个已验证组合。
- Windows 锁屏、睡眠和用户会话切换事件触发原生锁定，不恢复已经关闭的 SQLCipher 会话。
- 分类、网站、多账号、自定义字段、搜索、软删除、回收站、加密备份和恢复。
- 键盘焦点、状态播报、错误关联、缩放重排和锁定后解锁页的可用性改进。

## 升级前必须完成

1. 退出正在运行的应用。
2. 只使用项目发布页提供、代码签名有效且 SHA-256 与清单一致的安装包。
3. 保留应用数据目录和现有离线备份；不要把重新安装旧版作为 v2 保险库的恢复方案。
4. 覆盖安装完成后，首次解锁可能创建迁移前快照并升级安全头。安装成功不代表保险库迁移已经成功。

## 备份与恢复限制

- 本机备份包含加密数据库、安全头和完整性清单；备份不是主密码恢复机制。
- 恢复会先检查清单版本、文件摘要、主密码和 SQLCipher 完整性，通过后才替换当前保险库。
- 备份和当前保险库位于同一磁盘时，不能抵御磁盘故障、勒索软件、账户被接管或设备丢失。
- 用户必须自行把经过验证的加密备份复制到受控的离线位置，并保护主密码。
- 未知格式、损坏备份或恢复中断会被拒绝；不得通过创建空保险库绕过错误。

## 内存保护限制

- 应用和 SQLCipher 会在支持的路径上清除敏感工作内存，并在锁定时关闭数据库连接。
- 当前 Windows 构建启用 SQLCipher 内存擦除，但不提供操作系统内存页锁定或防换出保证。
- 页面文件、休眠文件、系统或应用崩溃转储、调试器、恶意软件和具有足够权限的本机进程仍可能获得内存副本。
- 锁定和退出会缩短暴露时间，但不能消除已经由操作系统或第三方工具保存的副本。

## 剪贴板与历史限制

- 复制敏感字段后，应用会在设定时间到达时检查剪贴板摘要；只有内容仍是本应用写入的同一值时才尝试清理，避免覆盖用户之后复制的内容。
- Windows 剪贴板历史、云剪贴板、远程桌面、输入法、截图、无障碍工具或第三方剪贴板管理器可能在清理前保存副本。
- 清理当前剪贴板不能可靠删除这些历史或同步副本。处理敏感信息前应关闭剪贴板历史和云同步，并在使用后人工检查。

## 已知限制

- 尚无 macOS、Linux、Windows on ARM 或 32 位 Windows 支持。
- 不支持使用 0.1.0 写入已经迁移为安全头 v2 的保险库。
- 正式最低硬件仍取决于 8 GiB、4 逻辑处理器 Windows 设备上的最终 KDF、安装和生命周期验收。
- 远程桌面、企业安全策略、受控文件夹访问和杀毒软件文件占用需要单独验证。

## 安全问题与恢复

- 安全问题按[安全披露流程](../04-security/SECURITY_DISCLOSURE.md)报告，不要在公开 Issue 中附带保险库、密码、Token、备份、缓存或转储。
- 遇到迁移或恢复失败时停止反复写入，保留全部原文件、迁移快照和错误类别，并按[恢复指南](RECOVERY_GUIDE.md)处理。
