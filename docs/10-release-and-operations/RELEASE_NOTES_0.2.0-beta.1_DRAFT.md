# 0.2.0-beta.1 发布说明草案

> 未获准发布；仅用于虚构测试数据。

## 重要变化

- 删除主密码、锁定/解锁、自动锁定、Windows 锁屏/睡眠联动以及所有 KDF 和 SQLCipher 代码。
- 应用启动后直接打开账号管理界面。
- 本地数据存储在未加密的 `password-manager.db`；备份也未加密。
- 不迁移、覆盖或删除旧 `vault.db`、安全头和旧加密备份。

## 已有功能

- 分类、网站、多账号、基础与自定义字段。
- 搜索、字段遮挡/显示/复制、网址打开。
- 级联软删除、回收站和批次恢复。
- 剪贴板条件定时清理。
- 明文 SQLite 备份、SHA-256 损坏检测和验证恢复。
- Windows 安装、覆盖修复和显式用户数据清理路径。

## 安全限制

任何能读取当前 Windows 用户应用数据目录的人或程序都能直接读取数据库与备份。切换应用、锁屏、睡眠或恢复不会触发应用锁定。Windows 剪贴板历史和第三方工具可能保留已复制内容。构建尚未正式代码签名。

因此该候选不得用于真实密码、Token、恢复码或其他真实秘密。
