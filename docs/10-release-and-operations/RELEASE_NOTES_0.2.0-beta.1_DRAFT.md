# 0.2.0-beta.1 发布说明草案

> 未获准发布；仅用于虚构测试数据。

## 存储变化

- Windows 桌面端以 SQLCipher 加密数据库。
- 随机数据库密钥由当前 Windows 用户 DPAPI 自动保护，启动时无需输入密码。
- 没有主密码、锁定、解锁、自动锁定或锁屏/睡眠联动。
- 加密备份包含 SQLCipher 数据库、DPAPI 密钥文件和完整性清单。
- 不迁移、覆盖或删除旧明文/旧加密测试库。

## 限制

DPAPI 保护通常绑定原 Windows 用户配置文件，备份不能保证跨用户或跨设备恢复。当前用户上下文恶意程序、管理员、运行期内存读取、屏幕和剪贴板不由静态加密解决。启动后数据会自动可见，构建尚未正式代码签名。

因此当前候选仍不得用于真实密码、Token、恢复码或其他真实秘密。
