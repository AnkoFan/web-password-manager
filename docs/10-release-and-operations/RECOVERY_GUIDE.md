# 恢复指南

> 状态：M2.5 本机备份恢复流程可用

1. 在锁定页选择本机备份。
2. 输入创建该备份时使用的主密码。
3. 勾选替换当前保险库确认。
4. 选择“验证并恢复所选备份”。

应用会先验证清单、摘要、主密码和 SQLCipher 完整性，再创建当前保险库回滚点并替换。错误密码或损坏备份不会覆盖当前保险库。

若启动时提示保险库文件不完整，停止写入并保留应用数据目录；M2.5 尚未提供恢复中断回滚文件的自动修复工具。不要手工删除 `.rollback-*` 或 `.restoring-*` 文件。

详细限制见[备份与恢复](../03-storage/BACKUP_AND_RESTORE.md)。
