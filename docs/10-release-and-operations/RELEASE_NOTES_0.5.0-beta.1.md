# WebPasswordManager 0.5.0-beta.1 发布说明

> M6 纯界面重构候选；所有开发、截图和回归仅使用明确标记的虚构数据。

## 主要变化

- 将横向账号表重构为“分类导航 / 网站列表 / 账号工作区”三层结构，1280×720 不再依赖主内容横向滚动。
- 账号工作区统一账号列表、核心字段详情、复制、显示、打开、编辑和删除入口。
- 账号编辑器按基础信息、补充信息和自定义字段分区；主邮箱与备注继续遵守 M5 固定语义。
- 设置页加入远洋蓝、靛青、紫罗兰、玫红、琥珀和青绿六种固定强调色，选择即时生效并写入现有应用设置。
- 主导航、搜索结果、回收站、设置、空状态和确认对话框使用统一设计令牌与组件密度。
- 450×640 使用单栏网站/账号层级导航；同时补充减少动效和 Windows 高对比度回退。

## 不变的安全边界

- 不修改保险库数据库 schema、SQLCipher/DPAPI 文件对、备份格式或 Rust 命令边界。
- 密码及敏感字段不进入列表和搜索响应，仍按明确操作读取。
- 主邮箱可搜索与复制；备注默认为非敏感多行字段且不进入搜索索引。
- 不新增云同步、导入导出、主密码、锁定、附件或联网能力。

## 验证

- 前端单元与组件测试、生产构建、架构检查、发布配置和敏感面扫描。
- Rust 单元测试、DPAPI/SQLCipher、备份恢复与文档测试。
- 应用内浏览器 1280×720、900×640 和 450×640 视觉、交互、控制台和横向溢出检查。
- Windows NSIS 候选构建及 SHA-256 记录。
