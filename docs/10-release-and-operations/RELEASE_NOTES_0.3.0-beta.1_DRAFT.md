# WebPasswordManager 0.3.0-beta.1 发布说明草案

> 状态：Windows 内部候选，尚未批准公开发布
>
> 数据要求：仅使用虚构测试数据

## 本次新增

- 分类、网站和账号按名称稳定排序，并可在当前分类内安全筛选网站、账号、用户名或邮箱。
- 离线密码生成器由 Windows 桌面端 Rust 后端使用操作系统安全随机源生成，支持长度和字符类别设置。
- 回收站支持多选批量恢复，以及带明确范围和不可恢复提示的永久删除。
- 批量恢复与永久删除均采用数据库事务；任一步骤失败时不会保留部分结果。

## 保持不变的安全边界

- 数据仅保存在当前 Windows 用户的本机目录；没有云同步或联网传输。
- SQLCipher 数据库密钥由 Windows DPAPI 绑定当前用户保护，应用启动后自动打开。
- 应用没有主密码、锁定或解锁功能；获得当前 Windows 会话访问权的人可能直接看到数据。
- 密码生成结果默认隐藏，填入账号后仍需点击保存；筛选不会读取密码或敏感自定义字段。
- 永久删除是数据库行删除，不保证擦除 SSD、文件系统快照、备份或其他历史副本。

## 安装与升级

- 目标安装包：`WebPasswordManager_0.3.0-beta.1_x64-setup.exe`。
- 支持从 `0.2.0-beta.1` 当前用户安装覆盖升级；旧进程运行时由安装器显示关闭提示。
- 安装器不得覆盖应用数据目录，默认卸载仍保留应用数据。

## 已知限制

- 候选安装包没有正式代码签名，Windows 可能显示未知发布者提示。
- DPAPI 保护通常不能跨 Windows 用户或跨设备恢复。
- 当前用户上下文恶意程序、管理员权限、运行期内存读取、屏幕捕获和剪贴板历史不由静态加密解决。
- 尚未完成独立安全评审；公开发布需项目所有者另行批准。
