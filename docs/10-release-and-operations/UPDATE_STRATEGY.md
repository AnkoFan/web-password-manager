# 更新策略

> 状态：M3 策略已定义 / 公开更新通道未启用
>
> 最后更新日期：2026-07-31

## 1. 范围

M3 只支持由用户启动的 Windows NSIS 覆盖安装，不实现后台更新、静默联网检查或自动下载。应用运行时继续保持完全本地。

## 2. 版本与来源

- 只接受项目发布页提供的版本化安装包及其 SHA-256。
- 正式公开包必须通过代码签名和独立哈希验证；未签名测试包不得作为更新来源。
- 安装包文件名、应用清单版本、Windows 文件版本和卸载注册表版本必须一致。
- 不复用失败发布的标签或文件名。

## 3. 覆盖升级

1. 关闭正在运行的应用。
2. 验证安装包签名、发布者、时间戳和 SHA-256。
3. 使用相同 product name、identifier 和 current-user 安装模式运行覆盖安装。
4. 安装器只替换程序文件，不删除应用数据。
5. 首次解锁旧保险库时，由应用完成迁移前快照、schema 事务和安全头 v2 提交。
6. 验证迁移快照、保险库完整性和应用版本后，才把升级判定为成功。

安装升级与保险库格式迁移是两个独立提交边界；任一成功都不能推断另一个成功。

## 4. 失败与回滚

- 安装器失败：保留应用数据，不尝试创建新保险库；重新安装已验证的同版本或更高版本。
- 迁移失败：保持最后一个已验证头/数据库组合和迁移前快照，按恢复指南处理。
- 不支持用旧应用写入 v2 保险库。回退程序版本前先保留完整应用数据目录和迁移快照。
- 未完成专门降级验收前，不把“重新安装旧版本”作为用户恢复方案。
- 磁盘不足、权限变化或文件占用时不得删除最后一个可用安装包或保险库副本。

## 5. 卸载

- 默认卸载只移除程序文件、快捷方式和卸载注册信息，保留保险库、备份、安全设置和 WebView2 数据。
- 卸载确认页可以显式选择删除应用数据；该操作必须与卸载确认组合使用。
- 清理范围只允许当前 bundle identifier 对应的 `%APPDATA%` 和 `%LOCALAPPDATA%` 目录。
- 静默卸载不得隐式选择删除应用数据。
- 静默卸载仅在调用者显式传入 `/DELETEAPPDATA` 时执行与可见复选框相同的当前 identifier 数据清理；普通 `/S` 继续保留数据。
- 覆盖安装前必须验证既有主程序文件可替换；文件被占用时在复制文件和写版本注册表之前退出，避免出现“版本已更新但程序仍为旧文件”的状态。
- 删除应用数据前应另有离线备份；删除后不承诺可恢复。

## 6. 验收

- [x] 隔离 identifier 的全新安装、同版本修复、覆盖升级和默认卸载通过。
- [x] 隔离升级和默认卸载保留虚构 sentinel。
- [ ] 正式 identifier 的 `0.1.0` 到 `0.2.0-beta.1` 覆盖升级通过。
- [ ] 旧保险库在安装升级后完成 v2 迁移并验证快照。
- [ ] 安装失败与被占用文件路径不破坏应用数据。
- [ ] 可见卸载页的显式清理只删除隔离应用目录。
- [ ] 正式签名与哈希验证通过。
