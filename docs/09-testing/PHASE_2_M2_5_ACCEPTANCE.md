1. 创建虚构保险库和“恢复基线”分类。
2. 打开设置页，确认默认 5 分钟自动锁定、30 秒剪贴板清理和失焦锁定。
3. 把清理期限改为 5 秒并保存。
4. 创建本机备份，确认主界面卸载并进入锁定/恢复页。
5. 使用错误密码恢复，确认显示失败且声明当前保险库未覆盖。
6. 使用正确密码恢复，确认重新进入保险库且“恢复基线”分类存在。
7. 检查页面身份、有效 DOM、错误覆盖层、控制台和桌面布局。
