# M3.4 Windows 生命周期与敏感残留验收

> 日期：2026-07-31
>
> 状态：原生事件实现和自动注入已通过 / 真实系统操作待人工验收

## 实现增量

- 保留默认的窗口失焦锁定和空闲超时锁定。
- 新增隐藏 Win32 顶层消息窗口，注册当前会话 WTS 通知。
- `WTS_SESSION_LOCK`、注销、控制台断开和远程会话断开都会关闭 Rust SQLCipher 会话。
- `PBT_APMSUSPEND` 会在进入挂起时锁定；自动恢复广播再次锁定，以覆盖固件未发送挂起广播的情况。
- 原生事件桥接使用容量为 1 的非阻塞队列；重复事件会合并，窗口过程不会因消息洪泛阻塞或无界占用内存。
- 返回、重新聚焦或唤醒均不会重新建立数据库连接。
- 锁定原因只记录固定枚举值，不包含窗口标题、用户名或保险库内容。

## 自动证据

Rust 测试覆盖：

- Windows 消息到固定锁定原因的映射。
- 创建真实隐藏窗口、进入消息循环并接收注入的 `WM_POWERBROADCAST/PBT_APMSUSPEND`。
- 重复生命周期事件只保留一个待处理锁定信号，且投递路径不阻塞。
- 既有会话门控、失焦事件和前端卸载路径。

这些测试证明消息监听链路可用，但不能替代真实 Windows Shell、固件和驱动产生的锁屏、切换用户与休眠广播。

## 人工步骤

每项均先解锁虚构保险库并显示虚构字段，触发动作后返回应用：

| 测试 ID | 动作 | 预期 |
| --- | --- | --- |
| SES-001 | `Win+L` 锁屏后重新登录 | 显示解锁页；旧详情和搜索结果不可见 |
| SES-002 | 进入睡眠再唤醒 | 显示解锁页；必须重新提供主密码 |
| SES-003 | 切换到另一个 Windows 用户再返回 | 显示解锁页；旧命令返回“保险库已锁定” |
| SES-004 | `Alt+Tab` 切换应用 | 默认设置下立即锁定 |
| SES-005 | 任务管理器结束进程后重启 | 从锁定状态启动；已提交数据可解锁 |
| SES-006 | 锁定前打开详情/编辑/搜索状态 | 锁定事件后主界面卸载，返回不恢复草稿或秘密 |
| SES-007 | 连续触发锁屏、恢复和失焦 | 幂等锁定，无崩溃、无自动解锁 |
| CLP-001 | 复制虚构秘密并等待超时 | 当前剪贴板内容未变化时被清理 |
| CLP-002 | 复制后用其他内容替换 | 应用不清理用户的新内容 |
| CLP-003 | 打开剪贴板历史 | 明确记录 Windows 可能保留历史副本的限制 |

锁屏、用户切换和睡眠会中断当前自动化会话，必须由测试人员在场执行；不得自动填写 Windows 登录凭据。

## 缓存、临时文件与转储扫描

异常退出后，收集实际存在的应用数据、WebView2 用户数据、Windows Error Reporting 转储和本次测试临时目录。不要扫描无关用户目录。对每个明确目录执行：

```powershell
node .\scripts\scan-test-canaries.mjs `
  --root "<明确的应用目录>" `
  --root "<明确的转储目录>"
```

扫描器以流式方式匹配 UTF-8 和 UTF-16LE，只输出命中的文件路径，不输出秘密上下文。固定夹具的验证结果必须为 `passed: true`。完成后按测试环境清理策略删除虚构保险库、缓存和测试转储。

2026-08-01 在当前 Windows 上使用隔离 identifier `io.github.webpasswordmanager.m3installtest` 启动 0.1.1 测试构建，等待 WebView2 初始化后强制结束进程。扫描其 `%LOCALAPPDATA%` 目录的 169 个文件，三个固定 TEST-ONLY 主密码/字段秘密/Token 标记均无命中，结果为 `passed: true`。随后通过隔离卸载器的显式 `/DELETEAPPDATA` 路径删除安装目录、注册项及该 identifier 的 Local/Roaming 数据；未扫描或清理正式 identifier。
