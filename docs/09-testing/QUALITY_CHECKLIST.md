# 质量检查清单

> 状态：M3 自动化检查已建立 / Windows 人工检查待完成
>
> 最后更新日期：2026-08-01

本清单适用于 Windows 公开测试候选。所有测试账户、网址、密码、Token、截图和保险库必须是标记为 `TEST-ONLY` 的虚构数据。

## 自动化质量门禁

- [x] TypeScript 类型检查、Vitest、架构边界、生产构建和敏感面扫描通过。
- [x] 锁定原因对所有已知 Windows 原生事件提供非空用户提示。
- [x] `Ctrl+K` 不穿透已打开的对话框，也不覆盖已经处理的键盘事件。
- [x] 表单错误通过 `aria-describedby` 关联，字段错误使用 `aria-invalid`。
- [x] 异步状态使用 `aria-live` / `role=status`，阻断错误使用 `role=alert`。
- [x] 删除确认在请求进行中禁用重复提交并显示进度。
- [x] 全局监听器只在应用层注册并在卸载时清理。
- [x] 顶栏和主导航的锁定按钮不把 React 点击事件传入锁定提示；锁定后可正常显示解锁页。

## 渲染级缩放预检

2026-08-01 使用浏览器开发原型和仅驻留内存的 `M3 TEST ONLY` 虚构保险库完成以下预检：

- [x] 900×640 最低物理窗口基线无页面级横向溢出、交互控件越界或顶栏裁切。
- [x] 600×427（900×640 的约 150% 等效 CSS 视口）完成导航折叠和内容重排，无页面级横向溢出或控件越界。
- [x] 450×320（900×640 的 200% 等效 CSS 视口）完成导航折叠、内容纵向分区和设置卡片单列重排，无页面级横向溢出或控件越界。
- [x] 创建页、解锁页、分类对话框和账号字段编辑器在 450×320 下保持可操作；长对话框限制在视口内并提供内部纵向滚动。
- [x] 锁定后解锁页正常渲染；修复后页面日志没有新增运行时错误。
- [x] 增加 Windows `forced-colors` 代码兜底：焦点、选中态、禁用态和无效字段在系统高对比度下具有非纯颜色语义或显式轮廓。

这些自动化结果证明 CSS 重排边界；下方已勾选项目另由当前 Windows 的真实 150%/200% 显示缩放、Narrator、高对比度和人工键盘遍历补充。

## Windows 人工可用性与无障碍

- [x] 仅使用键盘完成创建、解锁、搜索、新增、编辑、删除和锁定（2026-08-01 当前 Windows，全部使用虚构数据）。
- [x] 对话框打开后焦点进入对话框，`Tab`/`Shift+Tab` 不逸出；修复受控对话框的触发焦点记录后，`Escape` 关闭会返回触发控件（2026-08-01 自动化、浏览器渲染与当前 Windows 原生应用人工通过）。

- [ ] 连续失败、空状态、加载状态和不可恢复错误均有明确下一步。

## 发布前停止条件

以下任一项存在时不得创建公开测试候选：

- 人工无障碍或 Windows 生命周期清单未完成；
- 自动化门禁失败或存在未说明的跳过；
- 使用了真实凭据、真实保险库或无法确认来源的数据；
- 许可证、签名、独立安全评审或仓库治理尚未决定；
- 发布说明未明确备份、剪贴板历史和内存页锁定限制。
