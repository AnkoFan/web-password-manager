# 质量检查清单

> 所有测试、截图和人工操作只使用明确虚构的 `TEST-ONLY` 数据。

## 自动化

- [ ] TypeScript、Vitest、构建、架构边界和敏感面检查通过。
- [x] Rust 24 项测试通过：DPAPI、SQLCipher、仓储、备份恢复和命令边界。
- [x] 数据库非明文文件头、DPAPI 篡改拒绝和不完整文件对保护通过。
- [ ] UI/契约不存在主密码、锁定、解锁或自动锁定入口。
- [ ] 对话框焦点、Escape 返回触发按钮、错误关联与防重复提交回归通过。

## Windows 与渲染

- [ ] 启动直接进入主界面，设置页 DPAPI/SQLCipher 说明完整可见。
- [ ] 900×640、150% 和 200% 视口无关键裁切。
- [ ] 纯键盘、Narrator、高对比度和焦点指示可用。

## 停止条件

- 使用真实凭据或来源不明数据。

- 自动化门禁失败或存在未说明跳过。
