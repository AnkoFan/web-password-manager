# 安全测试用例

> 状态：M4 `0.3.0-beta.1` 候选验证中
>
> 最后更新日期：2026-08-02

所有自动化夹具、截图和人工验收只使用明确标记的虚构数据。旧的主密码、KDF、安全头和锁定用例属于历史方案，不再作为当前产品验收标准。

## DPAPI、SQLCipher 与文件边界

| ID | 用例 | 预期 | 类型 |
| --- | --- | --- | --- |
| SEC-001 | 当前 Windows 用户 DPAPI 保护并解开随机数据库密钥 | 往返一致，文件中不出现明文密钥 | 自动 |
| SEC-002 | DPAPI 密钥文件被篡改或格式非法 | 启动拒绝且不覆盖文件 | 自动 |
| SEC-003 | SQLCipher 数据库新建、写入和重开 | 逻辑数据一致，文件头不是普通 SQLite | 自动/Windows |
| SEC-004 | SQLCipher 数据库被篡改、截断或密钥不匹配 | 完整性检查拒绝，不返回部分业务数据 | 自动 |
| SEC-005 | 数据库或 DPAPI 密钥文件只有一个存在 | 安全停止，不创建或覆盖另一文件 | 自动 |
| SEC-006 | schema 高于当前支持版本 | 写入前拒绝并保持文件不变 | 自动 |
| SEC-007 | 日志、错误和测试输出扫描 | 不包含数据库密钥或虚构字段秘密 | 自动 |

## 备份与恢复

| ID | 用例 | 预期 | 类型 |
| --- | --- | --- | --- |
| BAK-001 | 创建加密备份 | `sqlcipher_export` 生成一致副本并保留 schema | 自动/Windows |
| BAK-002 | 验证备份清单、长度和 SHA-256 | 两个文件与清单完全匹配后才允许恢复 | 自动 |
| BAK-003 | 备份数据库、密钥文件或清单损坏 | 替换前拒绝，当前保险库不变 | 自动/Windows |
| BAK-004 | 双文件替换中途失败 | 回滚为恢复前的已验证数据库/密钥组合 | 故障注入 |
| BAK-005 | 来自其他 Windows 用户的 DPAPI 文件 | 明确拒绝并说明跨用户限制 | Windows |

## 前端与敏感操作

| ID | 用例 | 预期 | 类型 |
| --- | --- | --- | --- |
| UI-001 | 启动和重启 | 直接进入主界面，不出现锁定/解锁入口 | 自动/Windows |
| UI-002 | 列表、搜索和默认详情 | 不返回或默认显示密码明文 | 自动/浏览器 |
| UI-003 | 显示、复制与剪贴板超时 | 用户明确触发；只条件清理应用写入且未被替换的内容 | 自动/Windows |
| UI-004 | 分类、网站、多账号行内编辑 | 使用虚构数据保存，空密码编辑保留原敏感值 | 自动/浏览器 |
| UI-005 | 网站批量删除 | 确认数量准确，软删除后可逐项恢复 | 浏览器 |
| UI-006 | 对话框、错误与键盘顺序 | Escape 关闭；焦点顺序连续；错误与字段关联；提交不可重复 | 自动/Windows |
| UI-007 | 生产 UI 和命令契约扫描 | 不包含主密码、锁定、解锁或自动锁定能力 | 自动 |
| UI-008 | 名称排序与当前分类筛选 | 重启后顺序稳定；密码和敏感自定义字段不参与筛选 | 自动/浏览器 |
| UI-009 | 离线密码生成器 | Rust 使用操作系统安全随机源；结果默认隐藏、不会自动保存或进入日志 | 自动/浏览器 |
| UI-010 | 回收站批量恢复与永久删除 | 只操作明确选择；父子恢复排序且失败全回滚；确认数量、焦点和非安全擦除边界正确 | 自动/浏览器 |

## 构建、缓存与权限

| ID | 用例 | 预期 | 类型 |
| --- | --- | --- | --- |
| SUR-001 | 生产源码使用 Web Storage、直接剪贴板或控制台日志 | 静态门禁失败 | 自动 |
| SUR-002 | CSP 允许不安全脚本或非 IPC 连接 | 发布配置门禁失败 | 自动 |
| SUR-003 | Tauri 增加未批准的剪贴板、Shell、进程或网络权限 | 架构/权限门禁失败 | 自动 |
| SUR-004 | 生产包包含测试秘密、旧锁定 UI 或开发原型 | 敏感面扫描失败 | 自动 |
| SUR-005 | WebView2 缓存、临时目录与崩溃转储扫描 | 不包含唯一虚构秘密标记 | Windows |
| SUR-006 | npm 与 Rust 依赖审计 | 无未说明的中高风险项 | 自动 |

## 安装与发布

| ID | 用例 | 预期 | 类型 |
| --- | --- | --- | --- |
| REL-001 | 全新安装、启动和重启 | 单一 NSIS 安装入口可用，自动打开同一加密保险库 | Windows |
| REL-002 | 应用进程运行时覆盖安装 | 可见提示关闭旧进程；确认后继续，取消则不修改安装 | Windows |
| REL-003 | 同版本修复或复制失败 | 不误写新版本，不破坏应用数据 | Windows |
| REL-004 | 默认卸载 | 删除程序但保留应用数据 | Windows |
| REL-005 | 显式删除应用数据 | 二次确认后只删除当前 identifier 管理的数据 | Windows |
| REL-006 | 候选版本与 SHA-256 | 前端、Rust、Tauri 版本一致；哈希与独立记录匹配 | 自动/人工 |
| REL-007 | 未签名安装包 | 发布说明明确披露 Windows 可能显示未知发布者 | 审查 |

## 运行命令

```powershell
npm.cmd run check:frontend
npm.cmd audit --audit-level=moderate
scripts\cargo-test.cmd
npm.cmd run tauri -- build
```

候选提交推送后只查询一次 GitHub Actions 状态，不使用长期 `gh run watch`；本地或浏览器已覆盖的免费额度任务可立即取消。
