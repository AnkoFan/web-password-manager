## 2. 桌面环境证据

- 当前用户安装目录存在 `WebPasswordManager/web-password-manager.exe`。
- 当前用户本地应用数据目录存在配对的 `vault.header.json` 与 `vault.db`。
- 已生成并验证过 NSIS 当前用户安装包。

由于 Windows Computer Use 安全策略禁止自动操作密码管理器，自动化不能在桌面界面中输入主密码。以下最终 UI 项已由用户于 2026-07-30 人工确认：

1. [x] 完全退出 WebPasswordManager。
2. [x] 重新启动后显示解锁页而不是主界面。
3. [x] 输入错误密码不能进入。
4. [x] 输入正确密码可以进入主界面。
5. [x] 点击锁定后立即返回解锁页。

桌面 UI 人工确认结果：通过。
