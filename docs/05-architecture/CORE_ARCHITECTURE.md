# 核心架构

> 状态：已落地基础规则  
> 最后更新日期：2026-07-30

## 核心边界

应用由 React 界面和 Rust 本地后端组成。React 负责展示、输入和短期界面状态；Rust 负责会话、校验、加密、数据库和本机能力。

```text
React 页面 → 前端服务 → Tauri 命令 → 存储 / 安全
```

## 必须遵守

- 主密码只从创建或解锁页面传入 Rust，不进入浏览器存储。
- 数据库连接、密钥和完整保险库对象不返回前端。
- 列表只返回摘要；秘密按单字段读取或由 Rust 直接复制。
- 写入前检查数据库版本，不能用旧版本代码改写新格式数据。
- `lib.rs` 只负责应用启动和模块组装。

## 当前模块

- `commands.rs`：桌面命令、参数限制和稳定错误。
- `security.rs`：密钥派生及数据密钥包装。
- `storage.rs`：保险库文件、SQLCipher、结构创建和版本检查。
- `tests.rs`：跨模块安全与存储测试。
