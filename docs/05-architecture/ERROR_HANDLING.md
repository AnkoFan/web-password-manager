# 错误处理

> 状态：命令错误格式已落地  
> 最后更新日期：2026-07-30

## 命令格式

Tauri 命令失败时返回：

```json
{ "code": "vault_version_too_new", "message": "保险库由更新版本的软件创建，请升级应用后再打开" }
```

`code` 供前端判断流程，不能随意修改；`message` 必须可安全显示，不能包含密码、字段值、路径细节或请求对象。

## 前端规则

- 前端服务把未知异常转成 `unexpected_error`。
- 页面根据错误编号显示稳定提示，不通过字符串猜测流程。
- 密码错误、数据损坏、版本不兼容和文件不可读不能全部显示成同一原因。
- 恢复类错误使用阻断页面；普通操作失败使用字段提示或短通知。

## 日志

日志可以记录错误编号和操作名称，禁止记录命令参数、完整响应和秘密。
