# 模块生命周期

> 状态：ADR-014 现行规则
> 最后更新日期：2026-08-02

- 启动：检查 SQLCipher 数据库和 DPAPI 密钥文件是否成对存在。
- 首次创建：生成随机数据库密钥、创建 SQLCipher 数据库，并以当前 Windows 用户 DPAPI 保护密钥。
- 后续打开：验证文件对、由 DPAPI 解开密钥、完成 SQLCipher 完整性和 schema 检查后进入主界面。
- 使用：所有业务命令都要求当前数据库连接已通过启动验证。
- 对象切换：清理详情组件中的临时显示、草稿和敏感字段可见状态。
- 失败：文件对、DPAPI、SQLCipher 或 schema 任一验证失败时拒绝业务写入，不覆盖现有文件。
- 退出：停止短期任务、关闭数据库连接并释放可控的运行期状态。

当前产品没有锁定或解锁生命周期。未来后台任务必须持有可取消的应用生命周期标识，并在退出、恢复替换或保险库启动失败时停止，不能在无有效连接时继续返回业务数据。
