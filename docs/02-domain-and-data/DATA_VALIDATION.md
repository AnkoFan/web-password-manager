# 数据验证

> 用途说明：统一分类、网站、账号、字段、网址和主密码等输入的校验、规范化、错误反馈与安全边界。
>
> 状态：M2.4 领域校验已实现 / 导入与安全设置规则待后续阶段
>
> 最后更新日期：2026-07-30

## 1. 原则

- 界面可以提前提示，但领域层必须执行最终校验。
- 数据库约束负责最后一道完整性保护，不能代替业务错误提示。
- 不静默截断、转换或删除用户输入。
- 名称可以规范化，秘密值原则上保持用户原始内容。
- 错误提示说明如何修正，但不得回显主密码、密码、Token 或密钥。
- 导入数据与界面输入遵守同一核心规则。

## 2. 校验时机

| 时机 | 目的 |
| --- | --- |
| 输入过程中 | 提供长度、格式和重复提示，不频繁阻断 |
| 提交保存前 | 执行完整业务校验 |
| 领域对象创建或修改 | 防止绕过界面的非法状态 |
| 数据库写入 | 保证外键、唯一性和事务完整性 |
| 导入与迁移 | 拒绝或隔离不兼容数据，不静默修复 |
| 打开网址或复制 | 再次确认对象存在、保险库已解锁及操作允许 |

## 3. 文本处理

### 3.1 名称和标签

适用于分类名、网站名、账号显示名称和字段标签：

- 去除首尾无意义空白。
- 禁止空字符串和仅空白字符串。
- 保留内部空格和用户使用的文字大小写。
- 禁止 NUL 等无法安全持久化的控制字符。
- 换行不允许出现在单行名称和标签中。
- 比较重复项前使用 NFKC 规范化并执行 Unicode 小写转换；显示值仅去除首尾空白，保留用户输入的内部空格和大小写。

### 3.2 字段值

- 不自动去除密码、Token、私钥或普通字段值的首尾空格。
- 不自动修改大小写、换行或字符编码。
- 单行字段禁止换行时，应提示用户改用多行类型，不能静默删除换行。
- 粘贴超长内容时拒绝保存并显示允许范围。

## 4. 长度限制

初始上限用于防止误粘贴和资源滥用，后续根据真实数据调整：

| 内容 | 初始最大长度 |
| --- | ---: |
| 分类名称 | 100 个 Unicode 字符 |
| 网站名称 | 200 个 Unicode 字符 |
| 账号显示名称 | 200 个 Unicode 字符 |
| 字段标签 | 100 个 Unicode 字符 |
| 主网址 | 2,048 个字符 |
| 单行字段值 | 65,536 个字符 |
| 多行备注或密钥文本 | 1 MiB UTF-8 数据 |
| 搜索查询 | 500 个 Unicode 字符 |

实现应同时考虑字符数和编码后字节数。超过上限时拒绝保存，不截断。

## 5. 同名规则

初始决策：

| 对象 | 范围 | 规则 |
| --- | --- | --- |
| 分类名称 | 同一保险库 | 规范化后不允许重复 |
| 网站名称 | 同一分类 | 允许重复，但创建时提示 |
| 账号显示名称 | 同一网站 | 规范化后不允许重复 |
| 字段标签 | 同一账号 | 规范化后不允许重复 |
| 系统字段角色 | 同一账号 | 每种非空角色最多一个 |

理由：

- 分类和账号承担导航与区分职责，重名会增加误操作风险。
- 同名网站可能代表不同环境或入口，因此只提示。
- 字段标签唯一可以避免“复制某字段”产生歧义。
- 用户名字段值允许重复，不用于唯一身份约束。

同名检查不使用显示名称作为实体标识。

## 6. 分类校验

- 名称必填且符合单行文本规则。
- 名称在保险库范围内唯一。
- 排序值只能在当前保险库分类范围内使用。
- 删除非空分类不属于简单校验错误，进入数据生命周期确认流程。

## 7. 网站校验

- 名称必填。
- 分类必须存在并属于同一保险库。
- 主网址可为空。
- 网址非空时必须能够解析为绝对 URL。
- MVP 打开操作只允许 `https` 和 `http`。
- `https` 可正常打开；`http` 应提示连接不加密风险。
- `file`、`javascript`、`data`、`shell` 和未知协议不得交给系统打开。
- 保存网址和打开网址是不同动作：可以保存待修正的文本草稿，但只有通过打开校验的值才能启动浏览器。

## 8. 账号校验

- 所属网站必须存在。
- 显示名称必填，并在同一网站内唯一。
- 字段标识、排序和系统角色不能冲突。
- 一个账号可以暂时没有字段，但保存空账号时界面应提示。
- 编辑账号时必须检查其网站仍然存在。

## 9. 字段校验

- 所属账号必须存在。
- 标签必填，并在同一账号内唯一。
- 类型必须是当前支持类型，或进入“未知类型只读保留”流程。
- 密码系统角色和密码类型必须标记为敏感。
- 自定义字段不得伪造系统角色。
- 排序只在同一账号内比较。
- 类型变化不能无提示破坏现有值。
- 空值允许保存，便于保留结构；界面可提示删除长期空字段。

## 10. 数据库密钥边界

当前产品不接受用户主密码输入。数据库密钥规则为：

- 只允许 Rust 后端通过 Windows CSPRNG 生成 32 字节随机值。
- 前端和普通业务命令不能提交、替换或读取数据库密钥。
- DPAPI 文件必须满足格式、长度和当前 Windows 用户解开校验。
- 解开结果长度不正确时安全失败，不尝试截断或填充。
- 密钥和 DPAPI 明文材料不写入日志、配置、错误详情或联网服务。

未来若设计可携带加密导出，其口令规则必须通过独立 ADR 定义，不能复用或改变当前保险库打开流程。

## 11. 搜索输入校验

- 空查询显示默认页面或最近视图，不执行无界全文扫描。
- 去除搜索词首尾空白，但不修改保险库数据。
- 超过长度上限时提示缩短。
- 搜索文本不拼接为数据库语句。
- 搜索内容不写入普通日志。
- 保险库启动验证失败或数据库连接不可用时拒绝搜索。

## 12. 导入与迁移校验

- 验证格式版本和完整性后再解析业务对象。
- 未知字段必须保留或明确隔离，不能静默丢弃。
- 外键不存在、跨保险库引用或重复稳定标识属于阻断错误。
- 单条业务输入错误可以形成可审查报告，但不能悄悄跳过。
- 迁移写入必须使用新文件或事务，并在成功验证后替换。

## 13. 错误分类

| 类型 | 示例 | 用户处理 |
| --- | --- | --- |
| 必填错误 | 分类名为空 | 在字段旁修正 |
| 格式错误 | 无法解析的网址 | 修改或取消打开 |
| 重复错误 | 同网站账号名称重复 | 修改显示名称 |
| 关系错误 | 网站引用不存在分类 | 刷新、恢复或报告损坏 |
| 启动状态错误 | 文件对、DPAPI 或 SQLCipher 验证失败 | 保留数据目录副本并重新检查保险库 |
| 完整性错误 | 数据校验失败 | 停止写入并进入恢复流程 |
| 资源限制 | 字段内容过大 | 缩短或使用未来附件能力 |

错误消息不得包含秘密值或完整解密对象。

## 14. 验收标准

- [x] 界面校验和领域校验结果一致。
- [ ] 名称重复规则在新建、编辑和导入中一致（导入尚未进入范围）。
- [x] 密码和字段值不会被自动裁剪。
- [x] 超长输入被拒绝且原数据未被截断覆盖。
- [x] 危险协议不能被打开。
- [x] 跨保险库引用被拒绝。
- [x] 密码角色不能变为非敏感。
- [x] 搜索输入和校验错误不泄露秘密。
